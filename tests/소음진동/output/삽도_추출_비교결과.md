# 삽도(JPG) 기반 현장조사 데이터 추출 정확도 비교

## 실험 개요
- **목적**: 삽도 3종(영향예측지점도, 정온시설도, 측정지점도)에서 AI가 현장조사 데이터를 추출하여 보고서 자동완성 가능성 검증
- **방법**: 레퍼런스 3개(여주/청양/천안)에서 패턴 학습 → 괴산 금신리 삽도에서 데이터 추출 → 정답지와 비교
- **핵심 원칙**: 괴산 금신리 정답지를 보지 않고 삽도만으로 추출

## 1. 측정지점 (N·V-1)

| 이격거리 | **25m** | **150m** | **X** (6배 과대추정) |
| 비고 | **이서건설** | **주택** | **X** |

> **분석**: 측정지점은 프로젝트 바로 옆(25m)의 건설업체였으나, AI는 동심원 기반으로 150m로 과대추정. 측정지점도에서 N·V-1 마커가 프로젝트 경계 바로 옆에 있었지만, 동심원 최소 단위(250m)보다 훨씬 가까워 정밀 추정 불가. 비고(이서건설)는 삽도에 표시되지 않는 정보.

## 10. 자동화 기여도 분석

### Before (삽도 미활용)
- 자동 생성 가능 범위: **~80%** (구조, 법령, 측정값, 계산)
- `[확인 필요]` 항목: 19건 (예측지점 수, 시설명, 방향, 거리, 예측값 등)

### After (삽도 활용)
- `[확인 필요]` 잔여: **0건** (전부 추출/계산으로 대체)
- `[좌표 미추출]` 잔여: 16건 (XTM/YTM 좌표 — 삽도에서 추출 불가, 별도 GIS 필요)
- **전체 항목 중 완전 정확**: 약 **85~88%** (방향, 계산, 구조, 법령 등)
- **오차 있으나 합리적 범위**: 이격거리, 시설명 일부

### 자동화 범위 확장 평가

## 11. 한계점 및 개선 방향

### 확인된 한계
1. **근거리 정밀 추정 불가**: 0.25km 동심원 안쪽의 거리(25m, 151m, 175m 등)는 정밀 추정 어려움
2. **같은 방향 복수 시설 혼동**: 한 방향에 민가와 축사가 모두 있을 때 매핑 오류 발생
3. **XTM/YTM 좌표 추출 불가**: 위성사진에서 정밀 좌표 추출은 GIS 도구 필요
4. **비고 정보 한계**: 시설의 세부 이름(신흥농장, 미영농장, 이서건설 등)은 삽도 해상도 한계

### 개선 방안
1. **이격거리 측정도 이미지 활용**: 일부 프로젝트에 이격거리 수치가 표기된 별도 삽도 존재 (예: 청양 이격거리3.jpg)
2. **GIS 좌표 활용**: 사업개요에 포함된 좌표 정보를 기반으로 거리 정밀 계산
3. **실무자 검증 워크플로우**: AI가 1차 추출 → 실무자가 이격거리만 검증/수정 → 자동 재계산
4. **고해상도 이미지**: 삽도 해상도가 높을수록 시설명 라벨 인식 정확도 향상

---

## 12. 결론

**삽도 기반 추출은 자동화 범위를 80% → ~88%로 확장하는 데 기여하나, 이격거리 정밀도가 핵심 병목.**

- **방향(100%)**, **예측지점 수(100%)**, **시설명(75%)**: 삽도만으로 충분히 추출 가능
- **이격거리(50%)**: 동심원 기반 추정은 정밀도 한계 → 실무자 보정 또는 GIS 보조 필요
- **예측값 계산(100%)**: 이격거리가 정확하면 소음/진동 예측은 완벽 자동화 가능

**추천 워크플로우**: AI 삽도 추출(1차) → 실무자 이격거리 검증(5분) → 자동 재계산(즉시) → 보고서 완성
이 방식으로 실무 작업시간을 4~5일 → 0.5~1일로 단축 가능.
