> 이 문서는 vars 에서 기계적으로 생성된다 (`engine/fill_report.py`). 내용을 고치려면 vars 를 고치고 다시 뽑을 것.

검토 요약: **직접 채울 것 1건 · 확인할 것 5건 · 자동 채움 25칸**

## ❓ 실무자가 채워야 하는 것 (1건)

문서에는 `[확인 필요]` 또는 `-` 로 나간 자리다. 값을 지어내지 않았다.
건수는 **사실(vars 항목) 기준**이라 아래 ✅ 빈칸 수와 1:1이 아니다 — 본문 빈칸으로 가는 항목은 ✅ 목록에 `← ❓` 로 표시되고, **표 안 자리로 가는 항목은 ✅ 목록에 나타나지 않는다.**

| 항목 | 왜 비웠나 |
|---|---|
| 조사시기·품셈연도·하수도공표일 | 사업 조사기간·판 표기 (rule §6-2 판 통일) |

## ⚠️ 채웠지만 확인이 필요한 것 (5건)

삽도 판독(정밀도 낮음)이거나, 회사 표준이 없어 기본값을 쓴 항목이다.

| 항목 | 분류 | 근거와 한계 |
|---|:--:|---|
| 현황 서술 10문장 + 성상별·기초시설 표 | 계산 | 지역개황 vars 원천 — D2 일반화(W6~7) 때 자동 생성 승격 (rule §2) |
| 생활폐 배출량·인구·통계연보연도 | 계산 | 지자체 통계연보 — 값 저장소 연계 (rule §2) |
| 장비 대수 | 삽도△ | 소음진동편 목록 기준 각 1대 가정 — 대기질편으로 확정 (수질 rule §2-7 동일) |
| 인부계산방식 | 판단 | 수질 §3-6 갈림과 동일 — 두 파트 동시 확정 |
| 임목폐기물 절 방향 | 판단 | 미산정 4 / 없음 1 / 지장물 1 / 실산정 1 (rule §4) |
