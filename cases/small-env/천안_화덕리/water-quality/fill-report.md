## ❓ 실무자가 채워야 하는 것 (5건)

문서에는 `[확인 필요]` 또는 `-` 로 나간 자리다. 값을 지어내지 않았다.
건수는 **사실(vars 항목) 기준**이라 아래 ✅ 빈칸 수와 1:1이 아니다 — 본문 빈칸으로 가는 항목은 ✅ 목록에 `← ❓` 로 표시되고, **표 안 자리로 가는 항목은 ✅ 목록에 나타나지 않는다.**

| 항목 | 왜 비웠나 |
|---|---|
| 수질 측정값 8종·등급·측정일시·조사시기 | 인용 사업 — 인용원 성적서 필요 (rule §2-2) |
| 측정지점 위치·XTM/YTM | 인용원 지점 정보 (rule §2-1) |
| 배수유역 면적·개수 | 설계도서·지형 판단 (rule §2-4) |
| 침사지 개소·제원(WLH) | 설계 판단 — 개소 문구는 골든 자기모순 (rule §6) |
| 운영시 배수시설 종류 | 설계도서 (rule §5-3) |
