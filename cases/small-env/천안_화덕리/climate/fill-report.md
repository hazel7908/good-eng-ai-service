## ❓ 실무자가 채워야 하는 것 (1건)

문서에는 `[확인 필요]` 또는 `-` 로 나간 자리다. 값을 지어내지 않았다.
건수는 **사실(vars 항목) 기준**이라 아래 ✅ 빈칸 수와 1:1이 아니다 — 본문 빈칸으로 가는 항목은 ✅ 목록에 `← ❓` 로 표시되고, **표 안 자리로 가는 항목은 ✅ 목록에 나타나지 않는다.**

| 항목 | 왜 비웠나 |
|---|---|
| 조사시기 | 사업 전체 조사기간 — 수질과 동일 값 (rule §6) |

## ⚠️ 채웠지만 확인이 필요한 것 (4건)

삽도 판독(정밀도 낮음)이거나, 회사 표준이 없어 기본값을 쓴 항목이다.

| 항목 | 분류 | 근거와 한계 |
|---|:--:|---|
| 관측소 (최근접 KMA 지점) | 계산 | 사업지 좌표→최근접 관측소 판정 — KMA 지점 목록 소싱 후 자동화 (rule §2) |
| 기상연보 연도별 10년·월별 6종·일람표 | 계산 | 기상자료개방포털 API 또는 연보 — stats_registry 등재 대기 (rule §2) |
| 최다풍향 | 계산 | 바람장미 최빈풍 — KMA 데이터 후속 (rule §2) |
| 강수일 합 ↔ 수질 강우일수 일치 | 판단 | 파트 공유 값 — 두 파트 vars 동시 확정 (rule §2 ★) |
