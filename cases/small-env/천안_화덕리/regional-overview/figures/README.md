## 남은 결함 — 넣고 눈으로 볼 때 참고

| 삽도 | 결함 |

| 수계도 | **흐름 화살표가 2개**다 (정답은 6~7개). 저수지가 상위를 독차지하던 것은 고쳤는데(`hydro.py` 가늘기 문턱) 이번엔 너무 걸러졌다 |
