## 3. WRONG 4건 — 전부 매립처리시설

```
생성  2개소 · 2034년까지 · 누적량 1,635,565.8㎥
정답  1개소 · 2032년까지 · 누적량    66,026.2㎥   (공공 1개소만)
```

천안에는 공공(목천위생매립시설)과 산업단지(천안제3산단) 2개소가 있는데
**정답은 공공만 싣는다.** 골든셋 8건 모두 1개소씩이다.

원자료(`전국 폐기물 발생 및 처리현황`)의 시트 이름이 `공공매립` 인데도 산단 시설이
딸려 온다 — 자료 쪽 확인이 필요하다. → 확인요청 **H-5**

매립 표는 **마지막 열도 4:4 로 갈린다** (`잔여매립가능량` ↔ `사용기간`). → **H-4**

## 4. 줄 단위 — 회귀 지표

> ⚠️ **2026-08-25 부터 기준이 바뀌었다** — 중복 줄을 접은 **고유 줄** 기준이다.
> 이전 총줄 기준 수치(재현율 71.5%)와 직접 비교하지 말 것.

| 지표 | 값 |
|---|--:|
| 재현율 | 739 / 1,143 = **64.7%** |
| 정밀도 | 739 / 1,021 = 72.4% |
| 법령표 제외 재현율 | 358 / 721 = 49.7% |
| `[확인 필요]` | 328줄 |
| **기준 사업(원주) 흔적** | **1줄** (수정 전 7줄) |
| 부동소수점 오차 | **0줄** (수정 전 3줄) |

재는 스크립트: `scratchpad/score_ro.py`

> ⚠️ **법령표가 정답 줄의 3분의 1을 차지하면서 손대지 않아도 맞는다.**
> 이 지표는 **양(volume)** 을 재지 품질을 재지 않는다.
