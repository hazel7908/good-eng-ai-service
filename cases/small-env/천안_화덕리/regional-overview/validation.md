## 3. 매립처리시설 4항목 — 우리 오류가 아니다 ★

원자료를 직접 역추적해 갈렸다 (`catalog/probe_landfill.py`, 2026-08-25).

### ① 2행은 **판 차이**다

| | 2023판 (정답지 인용) | 2024판 (우리) |
|---|:--:|:--:|
| 목천위생매립시설 | ✅ | ✅ |
| **천안제3산단 폐기물매립시설** | **없음** | **신규 등재** |

정답지가 1개소인 것은 **그 시점에 시설이 하나였기 때문**이다. **둘 다 맞다.**
이 하나가 네 자리를 동시에 흔든다 — 개소 수 · 사용종료년 · 누적량 · 표 행수.

### ② 정답지의 누적량은 **자릿수가 깨져 있다**

```
정답지     "2023년까지 누적량 660,26.2㎥"     ← 쉼표 자리가 어긋나 있다
원자료 2023판  1,295,044.1
원자료 2024판  1,372,592.5
```

`66,026.2` 는 **두 판 어디에도 없다** (전 시트 역추적). 총매립용량 2,120,837㎥ 시설이
1999년부터 25년간 3.1%만 찼다는 뜻인데, 같은 표의 사용기간이 `1999-2032` 다.

### ③ 이름으로 거르지 않는다

`1-다. 공공매립` 시트 자체가 공공이고 **공공/민간 구분 열은 원자료에 없다.**
시트 정규식도 시트 하나만 먹는다 — 코드 버그가 아니다.
`산단` 제외 같은 휴리스틱은 **멀쩡한 시설을 떨어뜨릴 위험만 만든다.**

### ④ 남은 미검증 가정

골든셋 8건이 **전부 1개소**라 다음이 관측되지 않았다.

| 값 | 현재 처리 | 근거 |
|---|---|:--:|
| 누적량 | 시설별 합산 | 0/8 |
| 사용종료년 | 가장 늦은 해 | 0/8 |

## 4. 줄 단위 — 회귀 지표

> ⚠️ **2026-08-25 부터 기준이 바뀌었다** — 중복 줄을 접은 **고유 줄** 기준이다.
> 이전 총줄 기준 수치(재현율 71.5%)와 직접 비교하지 말 것.

| 지표 | 값 |
|---|--:|
| 재현율 | 739 / 1,143 = **64.7%** |
| 정밀도 | 739 / 1,021 = 72.4% |
| 법령표 제외 재현율 | 358 / 721 = 49.7% |
| `[확인 필요]` | 328줄 |
| **기준 사업(원주) 흔적** | **1줄** (수정 전 7줄) |
| 부동소수점 오차 | **0줄** (수정 전 3줄) |

재는 스크립트: `scratchpad/score_ro.py`

> ⚠️ **법령표가 정답 줄의 3분의 1을 차지하면서 손대지 않아도 맞는다.**
> 이 지표는 **양(volume)** 을 재지 품질을 재지 않는다.

### 남은 기준 사업 흔적 1줄

```
천안시는 "22년 생태계변화관찰 지역 현황, 원주지방환경청"상 …
```

**정답에는 이 절 자체가 없다.** 골든셋 8건 중 4건에만 있는 절이다
(원주·괴산 2건·충주). 절을 지울지는 판단이 필요하다.
