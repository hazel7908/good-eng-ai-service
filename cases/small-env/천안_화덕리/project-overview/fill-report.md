## ❓ 실무자가 채워야 하는 것 (2건)

문서에는 `[확인 필요]` 또는 `-` 로 나간 자리다. 값을 지어내지 않았다.
건수는 **사실(vars 항목) 기준**이라 아래 ✅ 빈칸 수와 1:1이 아니다 — 본문 빈칸으로 가는 항목은 ✅ 목록에 `← ❓` 로 표시되고, **표 안 자리로 가는 항목은 ✅ 목록에 나타나지 않는다.**

| 항목 | 왜 비웠나 |
|---|---|
| 면적·편입토지조서·토지이용계획 | 신청서류(면적조서·토지이용계획) 필요 — 환26-09 받은자료 규약 (rule §0) |
| 추진경위 날짜·시행자·설비·피해방지 | 사업계획서·설계 값 (rule §2) |

## ⚠️ 채웠지만 확인이 필요한 것 (4건)

삽도 판독(정밀도 낮음)이거나, 회사 표준이 없어 기본값을 쓴 항목이다.

| 항목 | 분류 | 근거와 한계 |
|---|:--:|---|
| 배경 서술 | 판단 | 5꼴 자유 서술 — 방향 제안 대상 (rule §2, 미팅 '단락 방향성') |
| 실시근거 서술·대상사업 기준 | 판단 | 용도지역(농림→다.항 7,500) 분기 — 확정 시 자동 (rule §4-1) |
| 협의기관 | 계산 | 천안→금강유역환경청 관측 — 관할 매핑 자동화 후보 (rule §2) |
| 피해방지 수량 ↔ 수질 침사지·배수시설 | 판단 | 동일 원천 — 두 파트 동시 확정 (rule §2 ★) |
