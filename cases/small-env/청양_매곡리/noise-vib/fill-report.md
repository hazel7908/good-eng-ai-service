## ❓ 실무자가 채워야 하는 것 (5건)

문서에는 `[확인 필요]` 또는 `-` 로 나간 자리다. 값을 지어내지 않았다.
건수는 **사실(vars 항목) 기준**이라 아래 ✅ 빈칸 수와 1:1이 아니다 — 본문 빈칸으로 가는 항목은 ✅ 목록에 `← ❓` 로 표시되고, **표 안 자리로 가는 항목은 ✅ 목록에 나타나지 않는다.**

| 항목 | 왜 비웠나 |
|---|---|
| 현황.조사시기 | 인풋에 현장조사 일자가 없다 |
| 현황.측정지점.이격거리_m | 인풋·삽도 어디에도 없다. 마을1(293m) 권역 추정만 가능 |
| 예측.일작업량_㎥ | 설계도서 필요. 대기질편(7.2.2) 자료가 없다. 표 19 두 칸이 [확인 필요] |
| 예측.지점[*].비고 | 시설명 상세는 현장조사 데이터 |
