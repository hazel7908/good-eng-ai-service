## 1. 결함 — 텍스트 검증으로는 절대 안 잡히는 것 ★

### 1-1. 표 캡션과 표가 쪽 분리된다 (Critical)

**괴산·청양 표 29 에서 동일하게 발생.** 앞 장 맨 아래에 캡션만 남고 표는 다음 장 맨 위에서
캡션 없이 시작한다. 캡션 아래로 페이지 절반이 빈다.

```
p18 하단 : <표 7.2.7-24> 최종 저감대책 수립 후, 예측소음도   (단위 : dB(A))
           ← 여기서 페이지 끝. 아래 절반이 공백
p19 상단 : ┌─────┬──────┬──── (표가 캡션 없이 시작)
```

- **행 수와 무관하다** — 8행(괴산)·10행(청양) 모두 발생한다.
- 원인은 표가 커져 현재 쪽에 안 들어갈 때 **표만** 다음 쪽으로 밀리는 것이다.
  캡션 문단에 "다음 문단과 함께" 속성이 없다.
- **실무에서 반려 사유급이다.** 캡션 없는 표는 표가 아니다.

### 1-2. `P - 10` 이 두 줄로 접힌다 (Major)

청양 표 29 첫 열. 두 자리 PP 번호에서만 발생한다 (`P -` / `10`).
열 폭이 한 자리 기준으로 잡혀 있다. **PP 10개 이상인 사업에서 항상 발생한다.**

### 1-3. 캡션의 `(단위 : dB(A))` 가 두 줄로 접힌다 (Minor)

청양 p18. 캡션 본문이 길어지면 오른쪽 탭 위치를 넘어간다.

### 1-4. 페이지 번호가 원주 값 그대로다 (확인 필요)

천안 출력은 263–279 쪽으로 매겨진다. 정답 천안은 251–264 쪽이다.
파트를 완본에 합칠 때 다시 매기는 것이 정상이라면 문제가 아니다 — **실무 확인 항목**.

## 2. 정상 확인된 것

| 항목 | 결과 |
|---|:--:|
| 머리글 — 홀수쪽 장 제목 · 짝수쪽 사업명 | ✅ 둘 다 정상 |
| 바닥글 `7.2.7 소음·진동` + 쪽번호 | ✅ |
| **표 행 확장 7·8·10 행** | ✅ 깨끗하다. 잘림·겹침 없음 |
| **셀 음영** (측정 평균 칸 · 최종예측치 열) | ✅ 원본 서식 유지 |
| **`delete_range()` 절 삭제** (천안 저감 2·3·4절) | ✅ **잘린 흔적 없음.** `1) 필요시 …` 뒤로 깨끗이 끝난다 |
| **삽도 교체** | ✅ 천안 측정지점도가 정확히 들어갔다. 왜곡·여백 없음 |
| 삽도 캡션 인용 접미 `(주변 사업지 측정자료)` | ✅ |
| 법령표 4종 레이아웃 | ✅ |
| `[확인 필요]` 노출 | ✅ 의도대로 보인다 |

> **가장 걱정했던 두 가지 — 행 확장과 절 삭제 — 는 문제가 없었다.**
> 실제 결함은 예상 못 한 자리(캡션 고아)에서 나왔다.

## 3. 할 일

| # | 조치 | 심각도 |
|:-:|---|:--:|
| 1 | **캡션 문단에 "다음 문단과 함께" 속성** 부여 — 베이스 문서에서 한 번 걸면 전 사업에 적용된다 | Critical |
| 2 | 표 29 첫 열 폭 확대 (두 자리 PP) | Major |
| 3 | 캡션 `(단위 : …)` 줄바꿈 | Minor |
| 4 | 쪽번호 재매김이 실무상 정상인지 확인 | 확인 |

1번은 **베이스 문서 쪽에서 고치는 것이 맞다.** 생성할 때마다 손대면 사업마다 반복된다.
