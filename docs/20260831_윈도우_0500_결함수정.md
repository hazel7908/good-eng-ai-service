## ① 실결함 — 천안 0726 성상별 5표에 원주 폐기물 통계가 그대로 실렸다 ★

`868`(관리구역㎢)·`366,306`(인구)·`1,949`(배출량) … 전부 **원주시 값**이다.
핸들러가 "값 없음, 스킵" 으로 두었던 바로 그 자리 (CLAUDE.md 함정: **자료가 없으면
건너뛰지 말고 비운다**).

**Mac 이 핸들러를 고쳐 두었다** (`engine/parts/small-env/resource-cycle.py` —
성상별 5표 선비우기: `원주시` 라벨 행을 비우고 라벨만 새 시군으로. 되먹임 대비
skip=i 방어 포함). **실행 검증은 안 됐다.**

### 할 일

```bash
python engine/generate.py small-env resource-cycle 원주_무장리   # 되먹임 먼저
python engine/smoke_check.py small-env resource-cycle 원주_무장리
python engine/generate.py small-env resource-cycle 천안_화덕리
python engine/smoke_check.py small-env resource-cycle 천안_화덕리
```

- 원주 되먹임이 없다(0726 은 천안으로만 생성했었다) — **이번에 원주부터** 만들어 표
  재현을 확인한 뒤 천안을 재생성한다.
- 천안 결과물에서 `868`·`366,306`·`1,949`·`799`·`938` 이 **사라졌는지 값으로 직접 확인**
  (`smoke_check` 의 leak_check 는 서술만 본다 — 표 유출은 통과시킨다, 수질 때 실증).
- ⚠️ 성상별 표 값 열 수(8·6·6·5·6)는 평면 추출 추정이다 — `blank_row` 는 셀 주소로
  걷기 때문에 열 수를 몰라도 되지만, 라벨 쓰기(`write_at`)가 옆 칸을 밀지 않는지 볼 것.
