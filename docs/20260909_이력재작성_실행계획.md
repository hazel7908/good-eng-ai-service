## 2. 실행 (맥에서 — 리허설 검증된 그대로)

```bash
cd /tmp && git clone --mirror https://github.com/hazel7908/good-eng-ai-service.git rewrite.git
cd rewrite.git
~/Documents/good-eng-ai-service/.venv/bin/git-filter-repo --force \
  --invert-paths --path _archive --path catalog/data/nas_index.json.gz \
  --replace-text  ~/Documents/good-eng-ai-service/raw_data/_pii/replace_text.txt \
  --replace-message ~/Documents/good-eng-ai-service/raw_data/_pii/replace_text.txt
git push --mirror --force https://github.com/hazel7908/good-eng-ai-service.git
```

## 3. 검증 (push 전, rewrite.git 안에서)

```bash
git rev-parse HEAD^{tree}          # == 기록해둔 재작성 전 트리 해시 (같아야 함)
git grep -l 박도예 $(git rev-list --all) | wc -l    # 0 (표본 몇 개 더)
git log --all --format=%B | grep -cE "박도예|허유미|조형범"   # 0
```
