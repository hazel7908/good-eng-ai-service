## 2. 우리는 이렇게 처리합니다 — 조치 불필요

| 상황 | 우리 쪽 처리 |
|---|---|
| 백업 덤프가 섞여 들어옴 | **크롤·카탈로그 제외 목록**으로 처리 (`기타자료/외장하드` 등 경로 지정) — 옮기실 필요 없습니다 |
| 폴더 위치가 바뀜 (정리 등) | 정본 카탈로그(290개 유니크 사업)가 폴더 **이름 신호** 기반이라 **자동 재생성**됩니다 |
| 계속 새 자료가 올라옴 (8월 말까지) | **변경 감지 도구**(스냅샷 diff)로 주기 재조사 — 보고서류(hwp/hwpx) 추가분을 자동 표시 |
| 업로드 완료 시점 | 최종 스냅샷 → 확정 카탈로그 + 전체 카테고리 지도 작성 (우리 작업) |

`0. 기타자료` 에 이미 들어온 것은 오늘 조사 완료 후 내용을 분석해서,
**보고서류가 섞여 있으면 카탈로그에 편입**하고 그 목록을 공유드리겠습니다.

## 3. 도구·산출물 상세 — 무엇이 어떻게 만들어져 있나

### 3-1. NAS 전수 인덱스 (스냅샷)

File Station API로 **폴더 트리 전체를 목록만** 추출합니다 — 파일 내용은 내려받지 않고
이름·크기·수정시각만 기록하므로, 수만 폴더여도 결과는 수 MB 텍스트입니다. 이 스냅샷이
아래 모든 도구의 원료이고, 같은 명령으로 언제든 동일하게 재현됩니다.

### 3-2. 정본 카탈로그 — "우리 회사 사업이 총 몇 건이고, 각각의 정본이 어디 있나"

전체 폴더를 **사업 단위로 자동 클러스터링**해 중복(담당자 사본·재업로드·연도 중복)을
걷어내고 유니크 사업 목록을 만듭니다. 현행 v1 은 **290개 유니크 사업** (잠정본 —
전수 조사를 반영한 **v2 재빌드는 업로드 완료 후 진행**).

- 사업마다: 정본 경로 · 연도 · 사업 종류(태양광/공장/야영장…) · 진행 상태(완료/취하/보류…) ·
  중복 폴더 목록 · **검수 플래그**(자동 판단이 약한 건 사람 확인용 표시)
- 정본 선택 기준: 실물 보고서 有 > 취하·반려본 제외 > 출처·완성도 순
- 산출물 2종: 개발용 인덱스(`nas_catalog.json`) + **현업 검수용 문서**(`nas_catalog_review.md`)
- 폴더가 이동·재정리돼도 **재실행 몇 초면 다시 만들어집니다** — 수작업 산물이 아닙니다

### 3-3. 변경 감지 리포트 (8/12 신규)

스냅샷 두 개를 비교해 **추가/삭제/변경 파일 전체 목록**을 날짜별 문서로 남깁니다.
보고서류(hwp/hwpx)는 ★, 파트 보고서 파일명 패턴(0722 대기질·0727 소음진동 등)은 † 로
자동 표시돼, 올라온 것 중 **우리 작업에 의미 있는 파일이 바로 드러납니다**:

```
추가 312 · 삭제 4 · 변경 27 — 보고서류(★) 18건
- ★† /backupenv/2025/○○리 태양광/2. 보고서/(본안) 0727 소음진동.hwp (2026-08-09)
```

8월 말까지 주기적으로 돌려 이 리포트를 공유드릴 수 있습니다 — 업로드하는 쪽에서도
"뭐가 올라갔는지" 목록으로 확인되는 부수 효과가 있습니다.

### 3-4. (원하시는 경우) 폴더 정리안도 자동으로 나옵니다

폴더를 정리하고 싶으시면 새로 설계할 필요가 없습니다 — 카탈로그에서 **정규화
폴더트리**가 자동으로 출력됩니다. 이미 v1 이 만들어져 있습니다
(`catalog/review/catalog_review.md` · 제안 취지는 `docs/nas_structure_overview.md` §5):

```
정본 카탈로그 v1 (290건)
├─ 환경/ (125)
│  ├─ 태양광/  …
│  │  └─ 환24-XX 평창군 미탄면 태양광 (완료)     ← 영역→종류→정규화 이름
│  └─ 기타/ …                                    + 검수 플래그 ‹중복?› ‹실물없음› 등
├─ 재해/ …
└─ 미분류/ (74)  ← 사람 확인 필요 목록도 자동 분리
```

강제 목표가 아니라 **참조 예시**입니다 — 검수·취사선택만 하시면 되고, 검수용
워크리스트(플래그 175건 목록)도 함께 있습니다. 물리 폴더를 이 트리대로 옮기든 안
옮기든 우리 자동화에는 영향이 없습니다 (§2 — 카탈로그가 자동 재생성되므로).

### 3-5. 파트별 자료 수집 규칙

파일명 번호 체계(`(본안) 0722*` = 대기질, `0727*` = 소음진동 등)를 규칙화해서
(`docs/naming.md`), 신규 사업이 올라오면 파트 자료를 **검색 한 번으로** 수집합니다.
실제로 보고서 자동 생성에 쓴 완성 보고서 11건(소음진동 7 + 대기질 4)이 이 경로로
확보됐습니다.

## 4. 참고로 알아두시면 좋은 것 (부탁 반, 안내 반)

1. **폴더 이름의 식별 신호만 유지해 주세요** — 연도·지역·사업명(있으면 관리번호).
   위치 이동·재정리는 전혀 문제없지만, 이름에서 이 신호가 사라지면 자동 분류가
   복구 불가능해집니다. 유일하게 우리 쪽에서 흡수 못 하는 경우입니다.
2. **저장장치 통째 백업에는 업무 무관·개인 파일이 섞이기 쉽습니다** — 공유 저장소
   성격상 한 번 확인해 보시면 좋을 것 같습니다 (우리 쪽 조사·카탈로그에서는 제외 처리).
