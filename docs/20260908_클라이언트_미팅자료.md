## 1. 요약 — 다섯 줄

1. **6개 평가 유형 165개 파트 전부**가 자동 생성 라인에 올라 있습니다 (환경 3종: 소규모환경·환경영향·전략환경 / 재해 3종: 소규모재해·재해영향·재해영향성검토).
2. 진행률은 **실무 건수 가중 82.3%** — 10월 말 목표(82.9%)를 사실상 한 달 앞서 도달했습니다.
3. 대표 파트 정확도: **소음·진동 94.8%** (정답 보고서와 항목 대조), 대기질·지역개황 등은 **"코드로 고칠 오류 0"** 상태입니다.
4. 이전 미팅에서 요청하신 6건 중 **5건 완료**(통계 자동화·빨간 표시·삽도·법령 최신화·인풋 리스트), 남은 1건(단락 방향성)도 **문장 수준은 가동 중**이며 절 단위 확장만 다음 단계입니다 (§4).

## 2. 우리가 만들고 있는 것 (지향점)

**"사업 인풋을 넣으면 보고서 초안이 나오고, 사람은 기계가 결정할 수 없는 자리만 맡는다."**

사람 몫으로 남는 자리는 두 종류이고, 채움 내역서가 이를 구분해 안내합니다:
**①자료가 없는 자리** — 아직 안 주신 자료(측정 성적서·계산 엑셀)거나, 현장에 가야 생기는 자료(주민탐문·사진). 주시는 대로 자동으로 들어갑니다
**②판단이 필요한 자리** — 회사 표준이 없어 갈리는 문형·현장 인상 서술. 표준을 정해주시면 자동으로 전환됩니다.
실물 예: 소음·진동 채움 내역서 = *직접 채울 것 4건 · 확인할 것 7건 · 자동 36칸*.

```
[신규 사업 인풋]          [축적된 지식]              [자동 생성]
 사업개요·신청서류    +   완성 보고서들에서       →   한글(HWP) 초안
 측정보고서·계산서        도출한 파트별 규칙           + 채움 내역서(어디를 왜 채워야 하는지)
```

세 가지 원칙을 처음부터 지켜 왔습니다:

| 원칙 | 뜻 |
|---|---|
| **지어내지 않는다** | 인풋에 없는 수치·지점명은 만들지 않고 `[확인 필요]`(빨간 글자)로 표시 |
| **틀린 값 0** | 목표는 "많이 채우기"보다 "채운 것은 맞기" — 그럴듯한 오답이 가장 위험하므로 |
| **사람의 판단 자리를 명시** | 자동으로 확정 못 하는 자리는 채움 내역서와 질문지로 넘김 |

완성률 수치보다 이 원칙이 중요합니다 — 검토자가 초안을 **믿고 시작**할 수 있어야 실무 시간이 실제로 줄기 때문입니다.

## 3. 어떻게 만드나 (방법)

1. **완성 보고서 학습** — 회사 NAS의 완성 보고서(전수 조사: 파일 73만+, 파트별 165~234건)에서 유형별 표본을 골라, 파트마다 "무엇이 사업 고유값이고 무엇이 고정인지"를 규칙으로 도출합니다. 규칙마다 근거 건수를 답니다(한 사업에서만 본 것은 규칙으로 쓰지 않음).
2. **베이스 문서 제작** — 완성 보고서에 빈칸을 뚫어 시작 문서를 만듭니다. 서식·법령표·고정 문구는 그대로 살아 있습니다.
3. **생성** — 사업 인풋에서 사실만 뽑아 빈칸을 채우고, 표는 계산해서 채우거나(자료가 없으면) 비웁니다.
4. **검증 게이트** — 저장할 때마다 자동 검사가 돕니다: 빈칸 잔여 · 기준 사업 값 유출(문장/표 값 단위) · 산출물 신선도 · 베이스 무결성 · 개인정보 검출. 마지막으로 PDF 육안 확인.
5. **채점** — 정답 보고서와 항목 단위로 대조해 파트마다 점수와 오류 원인을 기록합니다. (정답은 이 단계에서만 열람 — 생성 중에는 참조 금지)

| # | 요청 | 상태 | 내용 |
|:-:|---|:--:|---|
| 1 | 외부 통계 수집 자동화 + 통계 체계 관리 | ✅ | 지역개황 통계 **19종 중 15종 자동 수집** (상수도·하수도·폐기물·문화재 등). 각 통계에 **판(연도) 지문**을 남기고 발행처 최신판을 직접 받아 관리 — "출처 주석과 실제 사용 판이 다른" 기존 사례 4건도 이 과정에서 발견 |
| 2 | `[확인 필요]` 빨간 글자 표시 | ✅ | 저장 직전 자동 적용 — 산출물에서 빨간 자리만 찾으면 됨 |
| 3 | 삽도 자동 제작 (지도 위 라벨·화살표·마커) | ✅ | 요청은 "좌표를 찍어주면 반자동"이었는데, **주소 한 줄이면 전자동**까지 구현: 지오코딩 → 편입토지조서로 사업지 경계 자동 생성 → 지역개황도·수계도(흐름 화살표·하천명)·생태자연도(등급 판정까지) 등 6종. 레이어 분리(PSD) 산출로 수정도 쉽게 |

| 5 | 단락 방향성 (수치에 따라 서술 방향 변경) | 🔶 | **문장 수준은 가동 중** — 기준 상회 시 저감 절(방음판넬) 자동 삽입 분기, 보호지역 있음/없음에 따른 문형 전환, 통계 값을 서술 문장으로 짓는 조립 등. 남은 것은 **절 단위 증감**(사업에 따라 45줄짜리 절이 통째로 들고 나는 부류)과 **"방향 제안" 표시**(자동 확정이 안 되는 단락에 조건·후보를 채움 내역서에 제시) — 이전 미팅에서 합의한 대로 정밀 보완 단계 과제입니다 |
| 6 | 표준 인풋 리스트 | ✅ | **[별첨으로 준비했습니다](20260908_표준인풋리스트.md)** — 실제 생성에 쓴 사업 9건의 입력 실물 + `[확인 필요]` 잔여 197곳의 원천 전수 집계로 만들었습니다. 필수 5종(신청서류·개요·공문·측정 성적서·계산 엑셀)이 핵심이고, 미확정 2건(종목록 형식·재해 계산 파일)만 정해주시면 완결됩니다 |

## 5. 현재 도달점 — 숫자로

### 먼저 — 목표 수치의 뜻 (왜 100%가 아니라 82.9%인가)

10월 말 목표는 **자동화 완성이 아니라, 이후 소수 핵심 인원이 직접 사용하면서 부족한
부분을 메워갈 수 있도록 전체를 세팅해 놓는 것**입니다. 82.9%는 그 목표 상태를 완성도
사다리 점수로 계산한 산술값입니다:

> **실무 물량의 80%를 차지하는 두 유형**(소규모환경 76건·소규모재해 55건)은 **전 파트
> 러프 생성(B)까지**, 나머지 4유형은 **틀 완성(C)까지** — 이 상태의 점수가 정확히
> 균등 75.3 · 건수 가중 **82.9**입니다.

**나머지 17%는 실패분이 아니라 설계된 여백**입니다:

| 여백 | 내용 | 어떻게 채워지나 |
|---|---|---|
| B(85점)와 완성(100점)의 간격 | `[확인 필요]`로 명시된 **사람 몫** — 현장조사·판단 서술·아직 못 받은 인풋 | 실사용 루프에서 실무자가 채움 (채움 내역서가 안내) |
| 정밀 보완 | 회사 표준이 없어 갈리는 문형·표기 (§9 질문들) | 표준이 정해지는 대로 자동 통일 |
| 나머지 4유형의 C→B | 검토서·환경영향(본)·전략 등 | 실사용 우선순위에 따라 승급 |

즉 목표 도달 = **"쓰기 시작할 수 있는 상태"**이고, 그 이후는 사용하면서 메우는 단계(§8)로
설계돼 있습니다.

### 진행률 (완성도 사다리 기준)

파트마다 단계를 매깁니다: **틀 완성(C)** → **러프 생성·오류 0(B)** → **고정밀(A)**.

| 유형 | 파트 | 현재 | 비고 |
|---|:-:|---|---|
| 소규모환경영향평가 | 17 | **16개 파트 B 이상** (A 2개: 소음진동·대기질) | 잔여 1은 동식물상 — 종목록 인풋 형식 확인 대기 |
| 소규모재해영향평가 | 8 | **6개 파트 B** | 잔여 2(확률강우~홍수량 계산 장)는 계산 결과 인풋 방식 확인 대기 |
| 재해영향평가 | 8 | **6개 파트 B** | 소규모재해 라인을 재사용하는 구조가 실전 검증됨 |
| 재해영향성검토 | 5 | 틀 완성 | 러프 승급용 실사업 인풋 확보(9/9) — 승급 착수 대기 |
| 환경영향평가(본) | 30 | 틀 완성 | 표 배치 마무리 단계 (실작업 소진) |
| 전략환경영향평가 | 22 | 틀 완성 | 표 배치 마무리 단계 |

**종합: 유형 균등 76.4% · 실무 건수 가중 82.3%** — 10월 말 목표(75.3 / 82.9) 중 앞의 것은 이미 넘었고 뒤의 것은 0.6 남았습니다.

### 대표 파트 정확도 (정답 보고서와 항목 대조)

| 파트 (사업) | 정확도 | 의미 |
|---|:-:|---|
| 소음·진동 (천안) | **94.8%** | 문장·수치 오류 0 — 잔여는 인풋 자체가 없는 항목 |
| 대기질 (평창) | 61.6% | **계산 오류 0** — 잔여는 모델링 출력 등 인풋 영역 |
| 지역개황 (천안) | 63.1% | **오류 0** — 통계 표 37개 자동 채움 |

> 참고로 3월 PoC는 **소음·진동 한 파트만** 시험한 것이었고, 그때 같은 파트 정확도가 44%(오류 61건)였습니다. 즉 반년 사이의 변화는 두 축입니다 — **폭**: 1개 파트 → 6유형 165파트 / **질**: 같은 파트 기준 44% → 94.8%, 그리고 "틀린 값이 없다"는 성질의 확보.

## 6. 겉으로 안 보이는 기반 (품질·안전)

- **검증 게이트 5종** — 생성이 도중에 실패해도, 베이스가 오염돼도, 기준 사업 값이 남아도 자동으로 빨간불이 들어오는 구조를 실제 사고 사례마다 보강해 왔습니다.
- **개인정보 보호** — 인풋 수집 시 주민번호·실명·연락처 자동 검출·마스킹 도구를 상시 가동하고, 개인정보 대장 성격의 파일은 아예 수집하지 않는 원칙을 세웠습니다.
- **작업 재현성** — 베이스 문서·통계·규칙 모두 코드로 재현 가능하게 만들어, 담당자가 바뀌어도 다시 만들 수 있습니다.

## 7. 만들며 발견한 것 (부수 가치)

자동화 과정에서 기존 완성 보고서들을 기계로 전수 대조하다 보니, 사람 눈으로는 잡기 어려운 것들이 나왔습니다:

- **같은 보고서 안에서 값이 어긋나는 자리 13곳** (같은 수치가 표마다 다름) — 내부 변이표(골든셋 자기모순 절)와 파트별 검증 기록에 정리돼 있고, 요청 주시면 발췌해 공유드립니다.
- **법령 인용 구판 잔존** — 문화재보호법→문화유산법(2024) 등 개칭 미반영 10건, 부처 개편(기후에너지환경부) 미반영 고시 인용 27건 → 자동 최신화가 생성 시점에 치환합니다.
- **재사용 워크시트의 옛 값 잔존** — 계산 엑셀에 다른 사업 값이 남은 사례 → 확인 질문으로 정리했습니다.

즉 이 시스템은 생성기이면서 동시에 **기존 산출물의 검수기** 역할을 합니다.

| ~10월 말 | 목표선 확정 도달 + **정밀도 보완 단계** — 1순위는 **"방향 제안"**: 채움 내역서를 빈칸 목록에서 *단락별 작성 가이드*로 확장(갈리는 단락에 조건·후보 방향 제시 — 요청 5번의 완성), 이어서 절 단위 증감(사업 따라 절이 통째로 들고 나는 부류) |
| 10월 말 이후 | **판단 루프 완성** — 초안을 보고 "이렇게 고쳐줘" 하시면 지시를 반영해 재생성하는 흐름(값 일관성 자동 유지) → **실전 시범** 신규 사업 1건(청주 미원면 태양광, 정답 미공개 봉인 상태)으로 실제 업무 흐름 검증 |

## 9. 이번 미팅에서 정해주시면 좋은 것 ★

기술로 풀 수 있는 곳은 다 갔고, 남은 것은 **회사 표준이 없어 갈리는 항목**입니다. 전체 목록은 [확인 요청 질문지](실무자_확인요청.md)에 있고, 효과가 큰 다섯 개만 추리면:

| 질문 | 왜 중요한가 |
|---|---|
| **동식물상 종목록은 어떤 형식으로 받나요?** (엑셀 / 한글 표 / 스캔) | 형식에 따라 집계·귀화율까지 자동 가능 여부가 갈림 — 소규모환경 마지막 파트 |
| **확률강우~홍수량 계산은 어떤 파일로 하시나요?** (엑셀 양식?) | 재해 유형 4·5장 — 계산 결과를 인풋으로 받는 연결만 하면 됨 |
| **통계는 어느 시점 판으로 고정하나요?** (착수 시점? 제출 시점?) | 완성 보고서들끼리도 판이 갈림 — 기준만 정하면 자동 통일 |
| **시군구별 재해발생현황 표는 어디서 받으시나요?** (재해연보 책자엔 없음) | 입수 화면만 알면 그대로 자동화 |
| **지자체 통계연보 입수 경로** (일부 시군은 스캔 PDF뿐) | 지역개황 최대 병목 |
