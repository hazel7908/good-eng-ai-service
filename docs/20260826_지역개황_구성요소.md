## 1. 파이프라인 — 보고서 한 건을 만드는 길

흐름도는 결과보고 부록 A-1. 여기서는 각 단계가 무엇을 책임지는지 적는다.

| 파일 | 하는 일 | 도는 곳 |
|---|---|:--:|
| `engine/build_vars_regional.py` | 사업 인풋 + 통계 → `vars/regional-overview.json`. **판(연도)을 여기서 고정해 박는다** | 맥 |
| `engine/build_template.py` | 기준 사업(원주) 보고서 → 베이스 문서. 빈칸 64종을 뚫고 삽도를 걷어낸다 | 윈도우 |
| `engine/generate.py` | 베이스 + vars → `output.hwpx`. 토큰 치환 + 표 22개 셀 편집 | 윈도우 |
| `engine/build_figures_regional.py` | 지도 API → 삽도 PNG | 맥 |
| `engine/insert_figures.py` | PNG → `output.hwpx` 의 해당 자리. **캡션으로 자리를 찾는다** | 윈도우 |
| `engine/to_pdf.py` | `output.hwpx` → PDF (육안 확인용) | 윈도우 |
| `engine/fill_report.py` | 실무자가 채울 자리 목록 | 어디든 |

> `build_template.py` · `generate.py` · `to_pdf.py` · `fill_report.py` 는 앞선 두 파트에서
> 이미 있던 것을 **지역개황용으로 확장**한 것이고, 나머지 셋이 이번 신설이다.
