## 3. 천안 수질 생성 + 스모크

```bash
python engine/generate.py small-env water-quality 천안_화덕리
python engine/smoke_check.py small-env water-quality 천안_화덕리
python engine/to_pdf.py cases/small-env/천안_화덕리/water-quality/output.hwpx   # 육안
```

- vars 는 러프(B) 데모 상태다 — **[확인 필요] 빨간 글자가 많이 나오는 것이 정답**
  (13건: 측정값(인용 사업)·배수유역·IDF·강우일수 등). WRONG 0 이 게이트다.
- ⚠️ **표 편집(B1~B16)은 앵커·오프셋 미검증** — `parts/small-env/water-quality.py` 의
  경고 주석 참조. 표마다 로그와 결과 문서를 대조하며 skip·오프셋을 교정한다.
  특히: B9·B11·B15 (혼합·오수 표 — 캡션 앵커), B1 pH skip=1, "배수유역 1" skip 0~6 순서.
- 표 21·24류 함정 재독: 앵커 출현 횟수 세기 (hwpx.md `find_in_table 검색어 충돌`)
