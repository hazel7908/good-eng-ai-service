## 1. 전체 프로세스 요약

### 1.1 생성 파이프라인

```
[인풋 자료]                    [지식/룰]                    [기술 구현]
─────────────                ──────────                  ──────────
사업개요.txt          ──┐     CLAUDE.md 변수 매핑표        한글 API (win32com)
환경질측정_보고서.txt  ──┼──→  레퍼런스 4개 보고서 패턴  ──→  generate_hwpx_hwpapi.py
삽도 이미지(JPG) x2   ──┘     소음/진동 계산 공식           원주 템플릿 HWPX
                                                            ↓
                                                     [괴산 금신리 HWPX 출력]
```

### 1.2 변경 작업 구성

| 단계 | 방법 | 건수 | 설명 |
|------|------|:----:|------|
| 텍스트 교체 | `FindReplace` (전체 문서) | 14건 | 사업명, 주소, 측정값, 기준지역 등 |
| 테이블 셀 편집 | 한글 API 셀 탐색 + 덮어쓰기 | 9개 표 | 측정결과, PP데이터, 예측결과 등 |
| 이미지 교체 | ZIP 후처리 (BinData 교체) | 2건 | 측정지점도, 영향예측지점도 |
| 행 추가 | `TableAppendRow` | 4개 표 | PP 5행 → 8행 확장 (Table 14,22,25,29) |

### 1.3 지식 추출 경로

```
텍스트 인풋에서 자동 추출 가능한 변수 (A 분류):
  - 사업명, 주소, 소음/진동 측정값, 소음환경기준 지역구분 등

공식으로 자동 계산되는 변수 (B 분류):
  - 합성소음도, 이격거리별 소음도/진동도, 예측소음도/진동도

삽도 이미지에서 추출한 변수 (C-삽도 분류):
  - PP 지점명, 방향, 이격거리 (정밀도 낮음)

텍스트/삽도로 추출 불가능한 변수 (C-불가 분류):
  - XTM/YTM 좌표, 비고(시설명), 투입장비 작업량, 조사시기 정확일자
```

### 2.3 합성진동레벨 표 데이터 이상

생성 결과 텍스트 추출 시 합성진동레벨 표(Table 23)에서 다음과 같은 이상 데이터가 발견됨:

```
생성 결과 (L657-664): 6.9, 18.2, 15.4, 13.4, 10.5, 2.1, 1, 33.3
정답 (L597-610):       토공, 굴삭기, 1, 33.5, 36.4, 덤프트럭, 1, 33.3
```

이격거리별 진동값(1000m→50m 역순)이 합성진동레벨 표 셀에 침범한 것으로 보임.
원인: 이격거리별 진동도 테이블 편집 시 `find_in_table(hwp, "진동레벨(dB(V))")` 검색이 Table 24가 아닌 Table 23의 "합성진동레벨(dB(V))" 헤더를 먼저 매칭하여, 잘못된 셀에 값을 채운 것으로 추정.

### 3.3 오류 심각도별 분류

**Critical (보고서 품질에 심각한 영향)**:
1. 소음 목표기준 값 오류 (#43) — 법적 기준 수치가 틀림

**Major (수정 필요하지만 구조적 문제는 아님)**:

**Minor (실무적으로 사소한 차이)**:

9. 투입장비 작업량 (#36-37) — 설계도서 필요

## 4. 핵심 발견 및 교훈

### 4.1 기준 체계 혼동 문제

소음 관련 기준이 3가지 체계로 나뉘며, 이를 혼동하면 치명적 오류 발생:

| 기준 체계 | 분류 방식 | 계획관리지역 해당 | 적용 |
|----------|---------|:----------------:|------|
| 소음환경기준 | "가"/"나"/"다"/"라" | **"다" 지역** (65/55) | 현황 측정결과 비교 |
| 생활소음 규제기준 | 가. 주거지역 / 나. 그 밖의 지역 | **"나. 그 밖의 지역"** (공사장 낮 70) | 공사 소음 규제 |
| 생활진동 규제기준 | 가. 주거지역 / 나. 그 밖의 지역 | **"나. 그 밖의 지역"** (주간 70) | 공사 진동 규제 |

**정답의 소음 목표기준**: `'다' 지역의 공사장 낮 기준 65dB(A)` — 소음환경기준의 분류('다')와 그에 해당하는 65dB(A)를 사용. 이는 생활소음 규제기준의 "가. 주거지역" 공사장 낮 기준(65)과 같은 수치이지만, 분류명은 소음환경기준 체계를 따름.

**우리의 오류**: 생활소음 규제기준의 "나. 그 밖의 지역" 분류(70dB)를 적용 → 기준 체계 혼동

### 4.2 저감량 계산 방식

**우리의 방식** (단순 감산):
```
저소음장비 후 = 예측치 - 1.7 (굴삭기 저감량 직접 감산)
분산투입 후 = 그대로 (계산 미구현)
```

**정답의 방식** (합성소음도 재계산):
```
저소음 굴삭기: 71.7 - 1.7 = 70.0 dB(A)
저소음 합성소음도: 10*log10(10^(70.0/10) + 10^(74.9/10)) ≈ 75.7 → 저감 0.9dB
분산투입 후: 개별 장비 중 최대값(74.9)으로 재계산
```

### 4.3 삽도 추출의 한계

8개 PP 중 이격거리 오차 발생: P-2(5m), P-4(1m), P-6(5m), P-7(5m)
- 동심원 기반 추정으로는 ±10m 수준의 오차가 불가피
- 실무 투입 시 GIS 데이터 또는 실무자 확인 필수

### 4.4 "변경하지 않는 것"도 지식

발생원 현황 서술(#3): 정답은 원주 템플릿 텍스트를 유지했으나 우리는 변경함.
→ "이 항목은 사업별로 바뀌어야 하는가?" 판단 기준이 필요
→ 실무에서는 발생원 현황이 사업별로 달라야 하지만, 정답 작성자는 변경하지 않은 케이스
