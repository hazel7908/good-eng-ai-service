# HWPX 보고서 생성 워크플로우

## 전제 조건
- Windows + 한글 프로그램 설치
- Python 3.10+ (pywin32, Pillow)
- 인풋 파일: `cases/{카테고리}/{사업}/input/` 에 사업개요.txt, 환경질측정_보고서.txt
- 삽도 이미지: `raw_data/` 에 원본 JPG 파일

## 실행 절차

### 1단계: 인풋 파일 확인
- `cases/{카테고리}/{사업}/input/사업개요.txt` 읽기 → 사업명, 위치 추출
- `cases/{카테고리}/{사업}/input/환경질측정_보고서.txt` 읽기 → 측정값, 기준 지역 추출
- 용도지역 확인 → `.claude/rules/common.md`의 기준 체계 매핑 참조

### 2단계: 변수 추출 (O 분류)
- 텍스트 인풋에서 자동 추출 가능한 변수 목록화
- 해당 파트의 `.claude/rules/{카테고리}/{파트}.md` 변수 매핑 참조 (**명시적으로 읽을 것**)
- 추출한 변수는 `cases/{카테고리}/{사업}/vars/{파트}.json` 에 기록

### 3단계: 추출 불가 변수 확인 (X 분류)
- 텍스트/삽도로 추출 불가능한 변수 식별
- `[확인 필요]` 또는 `[현장조사 필요]`로 표시
- **인풋 없는 서술은 템플릿 텍스트 유지**

### 4단계: 계산 변수 생성 (계산 분류)
- 해당 섹션의 공식으로 자동 계산
- ⚠️ 저감량 계산은 **합성소음도 재계산 방식** 사용 (단순 감산 금지)

### 5단계: 생성 엔진 실행
- `engine/generate.py` 실행 (엔진은 파트를 모른다 — 베이스 문서 + vars 를 받아 채울 뿐)
  - 입력: `templates/{카테고리}/{파트}.hwpx` + `cases/{카테고리}/{사업}/vars/{파트}.json`
  - 출력: `cases/{카테고리}/{사업}/{파트}/output.hwpx`
- 한글 API (win32com) 사용
- FindReplace + 테이블 셀 편집 + 행 추가 + 이미지 교체

### 6단계: 검증
- `/validate-report` 스킬 실행
- 한글 프로그램에서 직접 열어 서식/레이아웃 확인

## 주의사항
- **`golden/` 은 생성 과정에서 절대 열지 않는다** (정답지 참조 금지 — 검증 단계에서만)
- 해당 파트의 오류 레지스트리 반드시 확인 후 동일 실수 방지
- `taskkill /f /im Hwp.exe` 로 기존 한글 프로세스 종료 후 실행
