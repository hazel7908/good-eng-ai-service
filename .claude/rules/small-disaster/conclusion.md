# 7장 결론 — 파트 지식 (n=2)

> **요약 재구성 파트 — 소환 0500 과 같은 부류.** 신규 값이 없다: 1장(개요 표)·4장(예측
> 결과)·5장(저감시설)의 vars 를 **승계**한다 (0500 §승계 규약과 동일 — 값 불일치 금지,
> vars 는 빌더가 복사로 만든다). 목표 B.

## ①구조 (2/2)

사업의 개요 표(사업명·위치·면적·시행자·기간·승인기관 — 1장 개요 불릿의 표 판) →
저감대책·저감방안 요약 서술(개소수·빈도·판단문) → **재해저감 총괄표**(재해유형 ×
예측결과 × 저감대책, 유역별 첨두홍수량·토사유출량 수치 포함) → 시설물제원 유지관리 리스트.

## ②변수→출처 — 전부 승계

| 자리 | 원천 |
|---|---|
| 개요 표 6행 | 1장 vars `사업` (개요 불릿과 동일 값) |
| 요약 서술 (임시침사지 n개소·침투통 n개소·검토 빈도·통수능 판단) | 5장 vars (계산 인풋) |
| 재해저감 총괄표 (첨두홍수량·토사유출량 개발전/중/후) | 4장 vars (계산 인풋) |
| 시설물제원 리스트 | 5장 vars (시설 제원) |

계산 인풋이 없으면(러프) 총괄표는 **비운다** — 기준 사업 값 잔존 금지 (rule §6-3 동일).

## ②-1 문체

요약 서술 끝은 `~영향성은 없을 것으로 판단된다`(공학 판단문, _category §2) + 조치 불릿(`·`).
