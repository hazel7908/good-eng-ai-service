# 6장 유지관리계획 — 파트 지식 (n=2)

> **반고정 서식 뭉치** — 실무지침 부록 표준서식(유지관리대장·점검리스트·정기점검표) 기반.
> 40k 로 크지만 사업 고유값이 적어 자동화가 쉽다. 목표 B.

## ①구조 (2/2)

유지관리대장 작성 항목 → 가배수로망도(삽도) → 단계별 유지관리 점검리스트 →
유지관리 업무의 구분 → 우기대비 정기 점검항목 → 배수관 점검·유지관리 → 일반관리 →
사면 정기점검표 → 행정사항.

## ②변수→출처

- 표준서식 본문(점검리스트·점검표·업무 구분): **고정** — 실무지침 부록 제1호 그대로.
  법령 인용표 규약(손대지 않는다) 적용.
- 대장에 들어가는 **시설물 목록·제원**(침사지·저류지·배수관 등): 5장 vars 승계.
- 가배수로망도: 삽도 (5장 배수계통과 동일 원천).
- 행정사항(관리책임자·착공 통보 등): 사업개요 인풋.

## ⑤분기 (1:1 — n=3 재확인 전 기준 사업 유지)

충주에만 `자연재해대책법 시행규칙 별지 제1호 서식` 절이 있다 — 판 차이 또는
승인기관 요구 차이. 서식 판 문제(§0)와 묶어 관찰.
