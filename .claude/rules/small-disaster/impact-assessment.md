# 4장 재해영향 예측 및 평가 — 파트 지식 (n=2) · 목표 C

> **계산을 재현하지 않는다** (전환계획 §4-4 확정 — AERMOD 와 같은 부류).
> 회사 계산 산출(도구는 확인요청 §7-3 답변 대기 — 본문 실측: 확률강우량은 **FARD2006**)의
> **결과 값을 인풋으로 받아** 표·서술을 전개한다. 방법론 서술(빈도해석·Kraven·RUSLE 이론,
> 실무지침 규정 인용)은 **반고정** — 베이스 유지.

## ①구조 — 계산 사슬 (2/2)

유발요인·설계빈도 → 홍수유출해석[관측소 → 고정-임의시간 환산 → 빈도해석 →
확률강우량 → 방재성능목표 비교 → IDF → Huff 분위 → 토양군·AMC → CN(개발전/중/후)
→ 도달시간(Kraven)·저류상수 → **첨두홍수량 비교**·수문곡선] → 저감시설 설치 검토 →
토사유출해석[원단위법 ‖ RUSLE(R·K·LS·C·P → 유사전달률 → 침식량) → **채택**] → 산사태.

## ②계산 인풋 규약 — vars `계산` 노드 명세 (C 수준 필요자료 리스트)

**전부 유역(`A`·`B`…) × 개발단계(전/중/후) 구조**가 기본이다. 러프에서 없으면 표를
비우고 `[모델링 필요]`.

| 값 묶음 | 구조 (천안 실측) |
|---|---|
| 관측소·자료기간 | 관측소명·기간 — 3장 수문특성과 동일 값 (kma.py 교차 가능) |
| 확률강우량 | 재현기간 7종(2·10·20·30·50·80·100년) × 지속기간별 매트릭스 |
| IDF 매개변수 | **General형 + 6차 전대수다항식형 병기** (천안 둘 다 수록 — §⑤) |
| CN | 토지이용상태 표(개발전/중/후 — **1장 투수/불투수와 값 일치 금지 위반 주의**) → CN값·AMC |
| 도달시간·저류상수 | 유역×단계: 유역면적(㎢)·유로연장(㎞)·평균유속·경사·Tc(min) / K |
| 첨두홍수량 | 유역×단계 × 빈도(30·50·100) + **임계지속기간(min)** + 비홍수량(50년, ㎥/s/㎢) |
| 토사유출 | 원단위(㎥/ha/storm)법 + RUSLE 인자(R·K·LS·C·P·유사전달률) → **채택표**: 유역×단계 × 퇴적토단위중량·정상강우년(tonnes→㎥/year)·단일호우(tonnes→㎥/storm) |
| 산사태 | 산사태위험도 등급 (산사태정보시스템 — 3장과 동일 원천) |

## ⑤분기

- **유역 수 n 가변**: 천안 A·B(2) · 충주 A·B·C(3) — 표가 유역별 행/절 반복.
  소환 수질 배수유역 fit_rows 경로 이식 대상.
- IDF 두 계열: 천안은 General형+6차 **병기** — `golden/small-env/_variants.md` §11
  (2024=6차 ↔ 2025 후반=조견표)과 같은 시기 갈림일 수 있다. n=3 에서 재확인.
- Huff 분위 = 3분위 (실무지침 권장 — 2/2 고정 취급).
- 설계빈도: 영구 50년·임시 30년 (실무지침 규정 — 고정, 서술로 인용됨 2/2).

## ⑥함정

- 서술 안에 채택 논리("직접 산정한 확률강우량이 기존보다 낮게 나오는 것은 정상적인
  결과이기 때문에 금회 산정치를 채택")가 길게 들어간다 — **반고정으로 두되 수치·
  관측소명만 뚫는다.** 문장 전체 토큰화는 과잉.
- 표 안 단위가 섞인다 (유역면적이 ㎦/㎢/ha 로 표마다 다름 — 천안 실측). 인풋 값에
  단위를 붙여 받을 것.

## ②-1 spec ✅ (09-03) — 11토큰 · 결과 표 6종 비우기 (C 베이스)

뚫은 것은 관측소(3장과 같은 토큰)·강우자료 기간/연수(`1973~2023년, 51개년` — `~`·`∼` 두 표기)·시군·
방재성능목표 공고·위험지구 요약뿐. 핸들러 `RESULT_TABLES` 가 확률강우량(재현기간×지속기간 머리 공유
표 여러 개)·첨두홍수량·도달시간·CN·토사유출량 채택·토지이용상태를 `[확인 필요]` 로 비운다 — **비우기가
실패하면 천안 계산값이 남는다**(WARNING 로그 확인 필수). 4,528줄 중 방법론 표·서술은 전부 반고정.
