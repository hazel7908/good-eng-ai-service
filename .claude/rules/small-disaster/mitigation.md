# 5장 재해영향 저감대책 — 파트 지식 (n=2) · 목표 C

> 4장과 같은 규약 — **계산 재현 금지, 결과를 인풋으로.** 침사지 이론부(NCHRP #70·
> Hazen·입경별 침강속도)는 반고정. ⚠️ **소환 수질(0723) 임시침사지와 같은 이론**이다 —
> 사업이 소환·소재평을 둘 다 하면 침사지 제원이 **두 보고서에서 일치**해야 한다
> (`calc_water.py` 값과 교차 검증 후보).

## ①구조 (2/2)

기본방향 → 저감대책 수립[개발 중 배수계통도 → 가배수로·물막이공 → **임시침사지 겸
저류지**(이론 → 유역별 산정 → 퇴사량·용량 → 방류관 → 상세도) → 임시사면보호공] →
저감방안 반영[영구 시설 · 사면·사방 · 지반보강] → 종합.

## ②계산 인풋 규약 — vars `저감` 노드 명세

| 값 묶음 | 구조 (천안 실측) |
|---|---|
| 침사지 산정 (유역별) | 머리값 4종: 침사지 내 유량(㎥/s)·배수구역 면적(ha)·토사유출량(㎥/storm)·침사지바닥 면적(㎡) + **입경 매트릭스**: 입경(극조사~) × 누가구성비·입경별구성비·침강속도·최소소요수면적·포착율 (보정계수 1.2 — 고정) |
| 퇴사량·용량 | 개발 중 퇴사량·침전부 용량 (유역별) |
| 방류관 | 연직방류관 에너지 손실·수위-방류량 관계 (시설 채택 시 — §⑤) |
| 시설 개소수·제원 | 임시침사지 n개소·침투통 n개소 등 — **7장 총괄표·6장 대장과 값 일치 금지 위반 주의** (승계 원천) |
| 상세도·개요도 | 삽도 (배수계통도 개발중 포함 — 재해형 삽도) |

## ⑤분기 — 저감시설 선택이 사업 공종을 따른다 (1:1 제각각)

천안: 연직방류관·보강토옹벽 / 충주: 가설방음판넬·세륜시설(예시도)·유역별 침사지 3개.
시설별 절·표·예시도가 **통째로 들고나는 구조** — 소환 청양의 "절 삽입" 부류.
러프 단계는 기준 사업 시설 구성 유지 + 안 쓰는 절은 [확인 필요] 표시.

## ⑥함정

- 입경 매트릭스 행 수가 토질(입경분석결과 — 4장 K값 유도와 동일 원천)에 따라 달라질
  수 있다 — 행 고정 가정 금지.
- 5장 산출(시설 제원)이 6장 유지관리대장·7장 총괄표로 **두 번 승계**된다 — vars 를
  단일 원천으로 (0500 승계 규약과 동일).
