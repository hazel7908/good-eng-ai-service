# 3장 기초현황 조사 — 파트 지식 (n=2: 원주 태장동 기준) · 목표 B

> 검토서 최대 장(원주 120k) — **재해이력·위험지구·방재시설 소싱의 본체**다
> (전환계획 §2-2 매트릭스의 그 자리). 소재평 3장 소싱 지도(`rules/small-disaster/
> _category.md` §3)와 절반 겹치고, 아래 신규 원천 3종이 검토서 쪽이 더 두텁다.

## ①구조 (원주 실측 — 횡성(10절)은 축약판이라 원주(21절) 기준)

기본방향 → 수문특성[관측소 위치도·제원 · **최근 10년 연도별/월별 기상**(kma.py 그대로) ·
수계도·유역도] → 토양·지질·지반[수문학적 토양유형] → **재해발생 현황**[시군 연도별·
기간별 재해발생현황] → **자연재해위험개선지구**[등급분류·유형별 지정기준(법령 반고정) ·
내수/토사/사면재해 **위험지구 현황**] → **방재시설 현황**[읍면동 내 방재시설물 목록].

## ②변수→출처 — 소싱 지도

| 절 | 원천 | 상태 |
|---|---|---|
| 기상 10년 (연도별·월별) | `kma.py` (ASOS — 소환 0721·소재평 3장과 동일) | 이식 |
| 수계도·유역도 | `watercourse.py`·`hydro.py` | 이식 |
| 토양유형 | 흙토람 (소재평 3장과 공통 신규) | 신규 |
| **재해발생현황** (이재민·인명·피해액 연도별) | **재해연보** (행안부 — 공공데이터) | 신규 ★ |
| **위험지구 현황** (지구명·하천·위치·사유) | **시군 풍수해저감종합계획** — 문서 인풋 성격 (전국 API 없음, 지자체 고시) | 신규 ★ |
| 자연재해위험개선지구 기준표 | 법령 반고정 (실무지침 별표) | 고정 |
| 방재시설물 목록 (읍면동 단위) | 시군 자료·풍수해계획 부속 | 신규 ★ |

★ 3종이 "재해이력 소싱" 패키지다 — 지역개황 통계 소싱과 같은 방법론(판 고정+지문)으로
만들 것. 위험지구·방재시설은 **표 행 수가 시군마다 다르다** (fit_rows).

## ⑥함정

- 재해발생현황 연도 구간이 판(연보 발행연도)에 따라 밀린다 — 지역개황 "판이 바뀌면
  행이 생긴다" 함정과 동일. 판 지문을 남길 것.
- 위험지구 표의 지구명·사유는 **기준 사업 시군(원주) 고유값 덩어리** — 표유출검사
  1순위 대상 (법천·청룡 등 지구명이 통째로 남는다).
