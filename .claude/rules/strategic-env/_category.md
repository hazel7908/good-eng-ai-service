# 전략환경영향평가 — 카테고리 공통 규칙

> 표본 1건 (2026-09-03 ⑭ 수확): **충북_수산천고명천** 하천기본계획 (2021.10 본안, 승인기관 충청북도). 22파트 txt.
> ⚠️ **n=1 이고 사업군이 하천 계획**이다 — 태양광 전략 표본이 없다. 골격은 참고, 값·서술은 전부 사업 고유.
> 슬러그: `docs/naming.md` 전략 표. 3단 문서(평가준비서→초안→본안) 중 **본안만** 수확됐다 (준비서는 전환계획 §2-2 ③).

## 1. 골격 — 본안 11장 + 별첨

요약문(1) → 개발기본계획 개요(2, **5,891줄** — 하천 계획 본체) → 대안(3) → 대상지역(4) → 지역개황(5) → 협의회 심의(6)
→ 주민·관계기관 의견(7) → **계획의 적정성(8, 4,694줄 — 상위계획 검토)** → **입지의 타당성(9)** → 결론(10) → 부록(11)
→ 별첨 오염총량 할당 유보(`load-allocation-deferral`).

9장은 소환 6장(입지타당성 검토표)의 **분야별 확장**이다: 9.1 생물다양성·서식지(동식물상·자연환경자산·지형생태축·
자연경관·**수질·수리수문**) / 9.2 환경기준 부합성(기상·대기·소음·자원순환) / 9.3 사회경제(환경친화적 토지이용) —
각 절이 `가. 현황 → 나. 영향 → 다. 저감` 소환 꼴. **`hydrology` 26,260줄**은 하천기본계획의 유역·홍수량 본체라
전략 일반이 아니라 이 사업군 고유(재해 4장 계산 인풋 규약 부류).

## 2. 다른 카테고리와의 대응

| 전략 | 같은 부류 |
|---|---|
| 5장 지역개황 | 소환 2장 (절 구성 동일 — 전환계획 §2-2 ③ "거의 동일") → `build_vars_regional` 이식 1순위 |
| 6장 협의회 심의 · 7장 의견수렴 | 본환 5·6장 (문서 인풋 X — 심의의견서·조치결과 표) |
| 8장 계획의 적정성 | 검토서 3장 관련계획 절 (상위계획 요약 — 시군·도 문서 발췌) |
| 3장 대안 | 본환 7장 |
| 9장 분야 현황 | 소환 7장 rule ②③ 참고 (측정·통계 원천 동일) |

## 3. 추출 특성

절 번호 텍스트 생존(`1.1.1`), `楴䵴` 없음 → 번호 정규식 파서. `08 계획의 적정성` 추출이 서로게이트로 죽었던 파트(⑭ —
`_sanitize` 이관으로 해결). 지명 밀도: `plan-overview` 659·`hydrology` 532·`flora-fauna` 224 — 하천명(수산천·고명천)이
본문 전체에 퍼져 있어 **일괄 치환 뒤섞임 위험 최고** 카테고리 (CLAUDE.md §7 — 하천명은 문장 단위 토큰으로).

## 4. 자동화 접근 (W6~7)

① 5장 지역개황 이식 → ② 4장 대상지역·10장 결론(반고정+승계) → ③ 9장 측정 분야(소환 계산기) → ④ 6·7장 틀(표만)
→ ⑤ 2·8장·hydrology 는 문서 인풋(C 틀 + `[확인 필요]`). 태양광 전략 표본이 오기 전에는 **골격 이상 가지 않는다**.
