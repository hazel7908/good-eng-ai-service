# 기상 (7.2.1) — 파트 지식

> **골든셋 7건** (2026-08-31 distill) — 수질과 같은 7개 사업. 변이표: `_variants.md` §12.
> **현황 단독 파트다** (예측·저감 절 없음, 7/7). 전부 기상연보 소싱 — 측정·판단 없음.
> 6쪽·표 8개·삽도 1(바람장미도). 계산·서술 생성은 `parts/small-env/climate.py`.

## §1 ① 구조 — 7/7 완전 동일

현황조사내용 표 → (1) 기상관측소(문장+일람표) → (2) 기상종합분석(요약 문장 ⚠️필드 +
10년 연도별 표 8열 + 평균행 ⚠️필드) → (가) 기온 (나) 강수량 (다) 평균습도 (라) 일조시간
(마) 강수일 (바) 풍속·풍향. 각 (가)~(바) = 요약 문장 + 월별 표 + `자) 기상연보 {연도}. 기상청`.

## §2 ② 변수 → 출처 — 전부 기상연보 (O/계산)

- **관측소**: 사업지 최근접 KMA 관측소 (지점번호 포함 — 원주(114)·청주(131)·천안(232)·
  충주(127)·정선군(217)·옥천(133) 관측). 일람표 값(좌표·H·Hb·ht·ha·hr)도 연보에서.
- **조사기간**: 연보 최신판 기준 **최근 10년** (7/7). 최신연도가 (가)~(바) 문장·표의 기준.
- **월별 표 6종**: 최신연도의 월별 기온(3행)·강수량·습도·일조·강수일·풍속.
- **10년 표**: 연도별 평균기온·평균최고·평균최저·강수량·강수일·습도·풍속·일조 + 평균행.
- **최다풍향**: 바람장미 최빈풍 (W 4/7·SW·E·NNE) — `{한글}({영문})` 표기 (`남서(SW)`).
- ★ **(마) 강수일 최신연도 합 = 수질(0723) 강우일수** — 파트 공유, 값 불일치 금지.
- 소싱: **`engine/kma.py`** (공공데이터포털 ASOS 일자료 → 기상연보 값). 월별 8종·연도별 8종을
  일자료에서 만든다. ★ **강수일 = 일강수량 0.1mm 이상인 날** — 수질 `강우일수`와 같은 값이어야 한다
  (원주 2023 = 108 일이 두 파트에서 같다)
  ⚠️ **API 마다 활용신청이 따로다.** 키가 맞아도 신청 안 한 API 는 **403** 이고 본문도 없다 —
  같은 계정의 생태·경관보전지역은 되는데 ASOS 만 403 이면 키가 아니라 신청 문제다
  (`kma.py` 가 그 안내를 띄운다). `--self-test` 가 원주 2023 으로 정의 재현을 먼저 검증한다
  (지역개황 통계 파이프라인 패턴). 그전에는 vars 수동 입력.

## §3 ③ 계산 — 요약 문장은 표에서 유도 (조건 분기 없음)

- (가)~(바) 문장: `총/평균 {값}, 최고 {값}({월}), 최저 {값}({월})` 꼴 — 월별 표에서
  최고·최저 월을 뽑아 채운다 (7/7 동형. §3-0 원값 원칙은 여기선 단순 조회라 무관).
- 10년 표 평균행: 연도별 값 평균 — ⚠️ 필드 깨짐으로 골든 표기 자릿수 미확인.
  기본 소수 2자리, **Windows 첫 생성에서 실측 후 확정**.
- 기온 문장 순서는 `평균최고 → 평균 → 평균최저` (7/7 — 표 행 순서와 같다).
