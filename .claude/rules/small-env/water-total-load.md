## §3 ③ 계산 (원주 역산 ✓ — `parts/…/water-total-load.py --self-test`)

- 발생부하량(kg/일) = 면적(㎡) ÷ 1,000,000 × 원단위(kg/㎢/일). **BOD 3자리 · T-P 4자리** 표시.
  답: 13,858e-6 × 4.24 = 0.05876 → `0.059` ✓ · × 0.467 = 0.006472 → `0.0065` ✓
- **합계는 표시값(반올림값)의 합** — T-P 원값 합 0.006547 → `0.0065` 인데 골든은 `0.0066`
  (= 0.0001 + 0.0065 + 0.0000). 수질 §3-0 "끝까지 원값" 원칙과 **반대**다 (1/1). 기본값은
  골든을 따르되 `[실무자 확인]` — 확인요청 **J-2**.
- 후: 13,934e-6 × 0.96 = 0.01338 → `0.013` ✓ · × 0.027 = 0.000376 → `0.0004` ✓
- 차감 = 후 − 전 = −0.046 / −0.0062 (문장에 그대로). **총괄표·할당부하량 표는 `0.00`/`0.000`**
  — 음수(감소)는 0 처리한 것으로 보인다 (1/1). J-2.
- 원단위 표는 기술지침 고정 12행 — 지목이 표에 없으면(`잡`은 `광천지…잡종지` 행 0.96) 매핑표로.

## §5 ⑤ 분기 (미관측)
