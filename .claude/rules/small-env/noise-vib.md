## §3 ③ 계산 공식

### 3-1. 합성 레벨

```
합성레벨 = 10 · log10( Σ 10^(L_i / 10) )
```

장비 구성만 알면 결정된다. 실질적으로 **조회표**다 (5/5 일치).

| 장비 구성 | 공종명 | 합성소음도 dB(A) | 합성진동레벨 dB(V) |
|---|---|:---:|:---:|
| 굴삭기만 | 부지다짐 | **71.7** | **33.5** |
| 굴삭기 + 덤프트럭 | 토공 | **76.6** | **36.4** |

검산: `10·log10(10^7.17 + 10^7.49) = 76.6` / `10·log10(10^3.35 + 10^3.33) = 36.4`

### 3-2. 거리 감쇠

```
소음:  SPL(d) = 합성소음도   − 20    · log10(d / 15)      r₀ = 15 m
진동:  VL(d)  = 합성진동레벨 − 16.17 · log10(d / 7.5)     r₀ = 7.5 m, n = 0.81
```

이격거리별 표(21·24)의 구분 거리는 사업마다 다르다. 소음 표의 첫 칸은 **목표기준에 도달하는 거리**를 쓴다 (괴산 57m ↔ 65.0dB).

### 3-3. 저감 단계별 소음도 ⚠️ 전면 수정

**골든셋 3건(원주·괴산·청양)에서 역산한 결과, 두 단계의 계산 방식이 서로 다르다.**

| 단계 | 계산 방식 | 결과 (합성 76.6 기준) |
|---|---|---|
| ① 저소음 건설장비 후 | **합성 재계산** — 굴삭기를 `75HP 미만` 등급(**67.5**)으로 교체 | **75.6** (저감 **1.0**) |
| ② 분산투입 후 | **이전 단계에서 단순 감산.** 감산값은 **1.7 ~ 4.9 중 선택** | 아래 표 |
| ③ 가설방음판넬 | **상회 지점에만.** 목표기준을 맞추도록 **역산** | §3-3-③ |

**① 검산**: `10·log10(10^6.75 + 10^7.49) = 75.63` → `76.6 − 75.6 = 1.0`

**검산 결과 (골든셋 5행, 2026-07-29)**: 위 ①②로 계산한 값이 원주 P-1·P-2, 괴산 P-1·P-4, 청양 P-2에서 **소수 첫째 자리까지 전부 일치**했다. 중간값을 반올림하지 말고 **끝까지 실수로 계산한 뒤 마지막에만 반올림**할 것 — 괴산 P-1은 `56.04 → 55.07 → 51.77` 로 가야 `55.1 / 51.8` 이 나온다.

**② 감산값의 정체**: 분산투입 표(28)의 `저감효과 1.7~4.9` 가 그대로 쓰인다.
`4.9 = 76.6 − 71.7`(굴삭기 단독) · `1.7 = 76.6 − 74.9`(덤프트럭 단독). **범위의 양 끝이고, 그 사이 값도 쓴다.**

| 사업 | 감산값 | 분산투입 후 합성 |
|---|:---:|:---:|
| 원주 | 1.7 (최소) | 73.9 |
| 괴산 | 3.3 (중앙) | 72.3 |
| 청양 | 4.9 (최대) | 70.7 |

> **공식이 아니라 작성자 판단이다.** 자동 결정하지 말고 **실무자 입력 항목**으로 둔다.
> 기본값이 필요하면 **1.7**(가장 보수적 — 저감을 적게 주장)을 쓴다.

#### ③ 가설방음판넬 — 목표기준에서 역산 (1/5, 청양)

②까지 해도 **여전히 목표를 못 맞추는 지점**에만 적용한다. 감쇠량은 표에 없다 — **목표기준에 딱 닿도록 거꾸로 잡는다.**

```
방음판넬 감쇠량 = (②단계 예측치) − (환경보전목표)      ← 소수 둘째 자리까지
```

청양 P-1 (축사, 12m): `72.6 − 12.64 = 59.96` ≤ 목표 **60** → `만족`

**적용하지 않는 지점의 칸은 `-` 로 둔다** (청양 P-2~P-10 전부 `-`). 즉 이 열은 상회 지점 한 곳만 값을 갖는다.

#### 최종 저감대책 표(29)의 열 구성이 사업마다 다르다 ⚠️

| 열 구성 | 사업 |
|---|---|
| 구분 · 지점명 · 이격거리 · 예측치 · 저소음후 · **분산후** · 최종예측치 · 환경보전목표 · 비고 | 원주, 괴산 |
| 〃 + **가설방음판넬** 열 추가 (분산후 다음) | 청양 |

- **청양은 분산투입 값에 감산량을 괄호로 병기**한다: `44.9(-4.9)`. 원주·괴산은 숫자만 쓴다.
- **괴산은 이격거리 칸이 비어 있다** (다른 표에는 있다). 표 29에서만 생략된 것이므로 임의로 채우지 말 것.
- 상회 지점이 없으면 방음판넬 열도 없다 → **베이스 문서(원주)의 8열 구성이 기본.**

<details>
<summary>이전 규칙이 왜 틀렸나 (재발 방지)</summary>

이전 규칙은 이렇게 적혀 있었다:

```
1. 저소음 굴삭기 = 71.7 − 1.7 = 70.0
2. 합성 = 10log10(10^7.00 + 10^7.49) ≈ 75.7
3. 저감량 = 76.6 − 75.7 = 0.9
```

**2번이 산수부터 틀렸다** — 그 식의 실제 값은 **76.1**이지 75.7이 아니다. 75.7이라는 결과는 굴삭기를 **67.5**로 넣었을 때 나온다.

`1.7`을 가져온 것도 오독이다. 저소음 장비 표의 `저감효과` 열은 **한 등급 위 동력과의 차이**다 (`73.4 − 71.7 = 1.7`, `71.7 − 67.5 = 4.2`). 저감을 적용하려면 **동력 등급을 낮춰 소음도 자체를 바꾼 뒤 합성을 다시 계산**해야 한다.

그리고 이전 규칙이 "❌ 틀린 방식"으로 금지한 **단순 감산은 ② 단계에서는 실제로 골든셋이 쓰는 방식**이다. 단계마다 다르다는 것을 몰라서 한쪽을 전면 금지했다.
</details>

## §4 ④ 분기 로직

### 4-1. 저감 구조 — 자동 판정하지 말 것 ⚠️

이전 규칙은 `상회 없음 → 단순 / 상회 있음 → 확장` 이분법이었다. **골든셋이 이를 부정한다.**

| 상회 PP | 저감 서술 | 방음판넬 **열** | 최종표(29) | 사업 |
|:--:|---|:--:|:--:|---|
| 0 | ① 저소음만 | 없음 | **없음** | 여주, 천안 |
| **0** | ① 저소음 → ② 분산투입 (+③ "필요시" 문장만) | 없음 | **있음** | **괴산, 원주\*** ⚠️ |
| 2 | ① → ② → **③ 실제 적용** | **있음** | 있음 | 청양 |

\* 원주는 상회 1건이지만 ②까지로 목표를 맞춰 방음판넬 열이 없다. **즉 갈림길은 "상회 여부"가 아니라 "②까지 해서 목표를 맞추는가"** 다.

**상회 0건일 때 최종표 유무가 갈린다** (여주·천안 없음 ↔ 괴산 있음). 골든셋만으로는 결정 규칙을 찾을 수 없다.

```
① 저소음 · ② 분산투입 후 예측치를 계산한다
   ├ 전 지점 목표 만족  →  방음판넬 열 없음 (원주·괴산 형태)
   └ 아직 상회 지점 있음 →  ③ 방음판넬 열 추가, 그 지점만 역산 (청양 형태)

최종 저감대책 표(29) 자체의 포함 여부:
   IF 상회 PP ≥ 1  →  포함. 확정
   IF 상회 PP = 0  →  [실무자 확인] 기본은 베이스 문서(원주) 구조 유지.
                      임의로 삭제하지 말 것 — 괴산 정답은 표가 있는 쪽이다
```

> 판정 낱말은 **`만족` / `상회`** 다. `초과`가 아니다 (`_category.md` §3).

### 4-2. 목표기준 문장의 지역 문자 ⚠️

```
주거시설 목표 소음 = 65 dB(A)   ← 5/5 고정. 용도지역과 무관
주거시설 목표 진동 = 65 dB(V)   ← 4/5 (괴산만 70)
```

지역 문자는 골든셋이 갈린다:

| 표기 | 관측 | 자기정합성 |
|---|:--:|---|
| `대상지역 ‘가’ 지역의 공사장 낮 기준 65dB(A)` | 4/5 | ✅ 생활소음규제 `가.주거` = 65 |
| `대상지역 ‘다’ 지역의 … 65dB(A)` | 1/5 (괴산) | ❌ 생활소음규제에 ‘다’ 분류 자체가 없음 |

**원주가 결정적이다** — 현황표는 소음환경기준 “나”, 생활진동규제 `나.그밖`인데 목표 문장은 ‘가’ 65다. 즉 **이 문장의 지역 문자는 사업의 용도지역을 따라가지 않는다.**

근거: 생활소음 규제기준 비고 3 — *"규제기준치는 생활소음의 영향이 **미치는 대상 지역**을 기준으로 적용"*. 영향을 받는 쪽이 민가이므로 `가.주거`가 적용된다.

```
기본값: ‘가’ 지역 / 65 dB(A)  (4/5)
예외:   괴산 재현 시에만 ‘다’
[실무자 확인] 항목으로 표시할 것 — 골든셋이 일치하지 않는다
```

### 4-3. 측정자료 출처

| 조건 | 도입 문장 | 삽도 캡션 |
|---|---|---|
| 자체 측정 (3/5) | `사업계획지구 주변 1개 지점의 소음 측정 결과, …` | `소음․진동 측정지점도` |
| 주변 사업지 인용 (2/5: 여주·천안) | `측정자료를 검토한 결과, …` | `소음․진동 측정지점도(주변 사업지 측정자료)` |

**두 곳이 함께 바뀐다.** 한쪽만 바꾸면 불일치가 남는다.

## §5 ⑤ 조건부 문구

| 조건 | 문구 |
|---|---|
| 전 지점 만족 | 소음: `장비투입에 따른 정온시설의 영향은 **미미할** 것으로 조사되었다` |
| 〃 | 진동: `장비투입에 따른 정온시설의 진동 영향이 **미미할** 것으로 조사되었다` |
| 〃 | 예측결과: `전 지점에서 기준치를 만족하는 것으로 예측되었다` |
| 일부 상회 | `… 영향이 **있을** 것으로 조사되었다` |
| 최종 저감 후 | `전 지점에서 환경보전목표를 만족하는 것으로 예측되었다` |

**최인접 거리 문장**: `가장 인접한 정온시설은 {최소 이격거리}m 이격되어 있어 …` — PP 이격거리의 최솟값. **소음·진동 두 곳에 같은 값**이 들어간다 (`common.md` 변수 일관성).

**예측지점 수**: `대표 시설 {N}개 지점을 영향예측지점으로 선정하였다` + 표 13 예측범위의 `반경 1.0km 이내({N}개 지점)`. **두 곳 모두** 바꿔야 한다.

## §6 ⑥ 오류 레지스트리

### 6-1. 규칙 자체가 틀렸던 것 (2026-07-28 골든셋 5건 재검증)

| # | 틀린 규칙 | 실제 | 원인 |
|:-:|---|---|---|
| R1 | 주거 진동 기준 **70** | **65** (4/5) | 괴산 1건에서 일반화. 괴산은 자기 안에서도 불일치 |
| R2 | 목표기준 지역 문자는 **소음환경기준 분류**(‘다’)를 따른다 | 4/5는 **‘가’** 고정, 용도지역 무관 | 〃 |
| R3 | 저감량 = 합성 재계산 (단순 감산 금지) | ①단계만 재계산, **②단계는 단순 감산** | 두 단계를 한 규칙으로 뭉갬. 게다가 예시 산수가 틀림 (75.7 → 실제 76.1) |

> **공통 원인**: 규칙이 **괴산 한 건**에서 도출됐다.
> → 새 규칙을 쓸 때는 반드시 `_variants.md` 로 5건을 대조하고 `(n/5)` 를 적는다.

### 6-2. 생성 결과가 틀렸던 것 (PoC)

**Critical**

| 오류 | 원인 | 교훈 |
|---|---|---|
| 소음 목표기준 `‘나’ 70dB` | 용도지역(계획관리)에서 생활소음규제 `나.그밖`을 유도 | **수치 65는 5/5 고정.** 용도지역에서 유도하지 말 것 (§4-2) |
| 최종 저감대책 수치 전부 틀림 | 저감량 계산 오류 | §3-3 |
| 합성진동레벨 표 데이터 침범 | `"진동레벨(dB(V))"` 검색이 표 23을 먼저 매칭 | 검색어를 `구분(m)` 이후로 특정 |

**Major**

| 오류 | 원인 | 교훈 |
|---|---|---|
| 발생원 현황 불필요 변경 | 정답은 템플릿 텍스트 유지 | 인풋 없는 서술은 **건드리지 않는다** |
| 예측범위 `5개 지점` 미변경 | 표 **안쪽** 텍스트가 치환에서 누락 | 표 내부도 치환 대상 (§5) |
| 소음 영향 `있을 것` (미변경) | 조건부 문구 미구현 | §5 |
| PP 이격거리 오차 4건 + 방향 1건 | 삽도 추출 부정확 | GIS 데이터 보강 필요 |

**Minor**

| 오류 | 교훈 |
|---|---|
| 이격거리 `25` → `25m` | 단위 접미사 |
| 측정일시 `~ 19일` → `~ 09월 19일` | 뒤쪽도 월 표기 |
| 진동 영향 `없을 것` → `미미할 것` | §5 문구표 |
