## 계산 공식

### 합성소음도

```
합성소음도 = 10 * log10(Σ(N_i * 10^(SPL_i / 10)))
```
- 굴삭기만: 71.7 dB(A)
- 굴삭기 + 덤프트럭: 10*log10(10^(71.7/10) + 10^(74.9/10)) = **76.6 dB(A)**

### 이격거리별 소음도

```
SPL(d) = 합성소음도 - 20 * log10(d / 15)
```
기준거리 r₀ = 15m

### 합성진동레벨

```
합성진동 = 10 * log10(Σ(N_i * 10^(VL_i / 10)))
```
- 굴삭기 + 덤프트럭: 10*log10(10^(33.5/10) + 10^(33.3/10)) = **36.4 dB(V)**

### 이격거리별 진동도

```
VL(d) = 합성진동 - 16.17 * log10(d / 7.5)
```
기준거리 r₀ = 7.5m, 기하감쇠정수 n = 0.81

### 저감량 계산 (⚠️ PoC 오류 수정)

**올바른 방식 — 합성소음도 재계산:**

```
1. 저소음 굴삭기 소음도 = 71.7 - 1.7 = 70.0 dB(A)  (75~140HP 저감효과)
2. 저소음 합성소음도 = 10*log10(10^(70.0/10) + 10^(74.9/10)) ≈ 75.7
3. 저소음 장비 저감량 = 76.6 - 75.7 = 0.9 dB (합성소음도 차이)
4. 분산투입 후 = 개별 장비 최대값(74.9)으로 소음도 재계산
```

**❌ 틀린 방식 — 단순 감산:**
```
저소음장비 후 = 예측치 - 1.7  (장비 단독 저감량을 직접 빼면 안 됨)
```

## 분기 로직

### PP 소음기준 초과 여부 → 보고서 구조

```
IF 모든 PP가 소음기준 만족:
    → 단순 구조
    → 저감방안: "필요시 저소음 건설장비 사용"
    → 최종 저감대책 표: 원주 템플릿에 있으면 포함 유지

IF 일부 PP가 소음기준 초과:
    → 확장 구조
    → 저감방안: 저소음장비 → 분산투입 → (필요시) 가설방음판넬
    → 최종 저감대책 표: 필수 포함
```

### 투입장비 수 → 계산 차이

```
굴삭기만:       합성소음 71.7, 합성진동 33.5
굴삭기+덤프트럭: 합성소음 76.6, 합성진동 36.4
```
