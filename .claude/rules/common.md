# 공통 규칙 — 환경영향평가 보고서 자동 생성

## 품질 기준

1. **환각 금지**: 인풋에 없는 수치나 지점명을 절대 만들어내지 말 것. 부족하면 `[확인 필요]`로 표시
2. **구조 준수**: 레퍼런스와 동일한 섹션 순서와 표 구조 사용
3. **변수 일관성**: 동일 변수가 여러 곳에 등장할 때 모두 같은 값 사용
4. **문체 통일**: 보고서 문체 ("~으로 조사되었다", "~할 계획이다")
5. **법령 정확성**: 법령 인용표는 레퍼런스에서 그대로 가져올 것

## 정답지 참조 금지

> 정답지는 **생성 과정에서 절대 참조 금지**. 실무에서는 정답지가 없다.
> 주어진 인풋 자료(사업개요 + 환경질측정 보고서)만으로 생성해야 한다.
> 정답지는 최종 검증 단계에서만 사용한다.

## 변수 데이터 출처 원칙

변수 값을 사용할 때는 반드시 **원본 텍스트 파일에서 직접 확인**해야 한다.
삽도(JPG 이미지)에서 추출한 데이터는 부정확할 수 있다 (PoC에서 이격거리 오차 확인됨).
텍스트에서 추출 불가능한 데이터는 `[확인 필요]` 또는 `[현장조사 필요]`로 표시한다.

## 변수 분류 체계

| 분류 | 의미 | 처리 방식 |
|:---:|------|----------|
| **O** | 텍스트 인풋에서 자동 추출 가능 | 스크립트 자동 처리 |
| **계산** | 다른 변수로부터 공식 자동 계산 | 스크립트 자동 처리 |
| **삽도△** | 삽도 이미지에서 추출 가능하나 정밀도 낮음 | 실무자 확인 필요 |
| **X** | 텍스트/삽도로 추출 불가 | 실무자 입력 또는 설계도서 필요 |
| **고정** | 모든 보고서에서 동일 | 템플릿 유지 |

## 기준 체계 매핑 (용도지역 → 환경 기준)

### 세 가지 기준 체계의 관계

소음·진동 관련 기준이 3가지 **서로 다른** 체계로 분류됨. 혼동하면 치명적 오류 발생.

| 기준 체계 | 분류 방식 | 용도 |
|----------|---------|------|
| **소음환경기준** | "가"/"나"/"다"/"라" | 현황 측정결과를 기준과 비교할 때 |
| **생활소음 규제기준** | 가. 주거지역 / 나. 그 밖의 지역 | 공사 소음 규제 기준 |
| **생활진동 규제기준** | 가. 주거지역 / 나. 그 밖의 지역 | 공사 진동 규제 기준 |

### 용도지역별 매핑표

| 용도지역 | 소음환경기준 | 생활소음규제 | 생활진동규제 |
|---------|:----------:|:----------:|:----------:|
| 녹지지역 | "가" (50/40) | 가. 주거지역 | 가. 주거지역 |
| 보전관리지역 | "가" (50/40) | 가. 주거지역 | 가. 주거지역 |
| 생산관리지역 | "나" (55/45) | 가. 주거지역 | 가. 주거지역 |
| **계획관리지역** | **"다" (65/55)** | **나. 그 밖의 지역** | **나. 그 밖의 지역** |
| **농림지역** | **"다" (65/55)** | **가. 주거지역** | **가. 주거지역 (65/60)** ⚠️ |
| 상업지역 | "다" (65/55) | 나. 그 밖의 지역 | 나. 그 밖의 지역 |
| 전용공업지역 | "라" (70/65) | 나. 그 밖의 지역 | 나. 그 밖의 지역 |

> ⚠️ **농림지역이 이 표의 유일한 예외다** (천안 화덕리, 2026-07-31 실측).
> 소음환경기준은 "다" 인데 생활진동규제는 `나` 가 아니라 **`가. 주거지역`(65/60)** 을 쓴다.
> 즉 **"소음이 '다' 면 진동도 '나'" 라는 유추는 성립하지 않는다.**
> 용도지역이 위 표에 없으면 **유추하지 말고 인풋(측정결과 표의 기준 행)을 따를 것.**

### PoC 오류 사례: 소음 목표기준 혼동

괴산 금신리 = 계획관리지역.

- 소음환경기준: **"다" 지역** → 주간 65, 야간 55
- 생활소음 규제기준: **"나. 그 밖의 지역"** → 공사장 낮 70

소음 목표기준 서술에는 **소음환경기준 분류('다')를 사용**한다:
```
✅ 정답: "대상지역 '다' 지역의 공사장 낮 기준 65dB(A)"
❌ PoC 오류: "대상지역 '나' 지역의 공사장 낮 기준 70dB(A)"
```

## 공통 변수

모든 섹션에서 사용되는 변수:

| 변수 | 추출 소스 | 치환 대상 |
|------|---------|---------|
| 사업명 | 사업개요.txt L1 | 본문 전체, 머리글, 바닥글, 표 |
| 사업 위치 | 사업개요.txt L1에서 파싱 | 사업명 내 포함 |
| 용도지역 | 환경질측정_보고서.txt에서 확인 | 기준 체계 매핑에 사용 |
