# 환경영향평가(본안) — 카테고리 공통 규칙

> 표본 1건 (2026-09-03 ⑭ 수확): **횡성_벨라스톤CC** 골프장 9홀 증설 (환24-30, 2025.11 재협의 본안,
> 1,239,132.2㎡). 30파트 txt. ⚠️ **n=1 — 전부 관측이지 규칙이 아니다.** 슬러그: `docs/naming.md` 본환 표.
> ⚠️ **태양광이 아니다** — 골프장이라 소환 골든(태양광 7건)과 사업군이 다르다. 사업 유형 차이와 서식 차이를 분리해 볼 것.

## 1. 골격 — 15장 (전환계획 §2-2 예측과 일치)

요약문(1) → 사업개요(2) → 대상지역(3) → 지역개황(4) → **심의 결과(5)·주민의견(6)·대안(7)** ◆ → 환경보전목표(8) →
**9장 분야별 현황·예측·저감·사후조사**(9.1 자연생태 2절 / 9.2 대기 3절 / 9.3 수환경 1절 / 9.4 토지 3절 / 9.5 생활 3절 /
9.6 사회경제 1절 = **13절**) → 전략 협의내용 반영(10) → 저감·사후조사(11) → 불가피 영향(12) → 주민피해(13) → 결론(14) → 부록(15).

각 9장 절은 `가. 현황 (1)조사항목 (2)조사범위 (3)조사방법 (4)조사결과 → 나. 영향예측 → 다. 저감방안 → 라. 사후환경영향조사`
— 소환 7장 절과 같은 4단 골격에 **`라. 사후환경영향조사` 가 더 있다** (본환 고유 — 사후조사 계획 표).

## 2. 소환과의 거리 — **spec 준용은 안 된다, rule 만 참고** (09-03 실측)

소환 spec 의 고정 골격을 와일드카드로 본환 골든에 대조: **19/98 = 19%**. 기상만 9/11 (기상연보 서술이 같은 꼴),
나머지는 0~3/N. 재평(60%)과 달리 **서식 계보가 다르다** — 같은 회사 문서지만 본환은 소환 서식의 복사본이 아니다.
→ 본환 파트 rule 은 소환 rule 의 ②변수·③계산·⑥함정을 **참고**하되 ①구조는 본환 골든에서 새로 잡는다.
   베이스는 본환 원본 hwp(`raw_data/nas/env-impact/`)를 따로 뚫는다. 준용 spec 층(재평식)은 만들지 않는다.

## 4. 문체·표기

`조사되었다`·`예측된다`·`계획이다` — 소환과 같다. 9장 절 제목이 `9.2.1 기 상`(띄어쓰기)·`9.3.1 수 질(수리·수문)`
처럼 **머리글 판과 본문 판이 다르다** (`수 질)` 잘린 머리글 실측) — 치환 앵커로 쓰지 말 것. 절 번호가 텍스트로 살아
있다(`1.1.2`) — 재해의 `楴䵴` 마커와 달리 **번호 정규식 파서**가 맞다(재평 PDF 파서와 같은 부류).

## 5. 추출 함정 (⑭ Windows 실측)

- `extract()` 짝 없는 서로게이트 — `_sanitize` 를 함수 안으로 옮김. **실패한 `write_text` 는 0바이트 파일을 남긴다** —
  `appendix-2` 20줄은 스캔 이미지라 정상, 그 외 20줄 이하 파일은 재추출 의심.
- 원본 NAS 경로가 연도 폴더(`환경/2024/`)로 재편됐고 옛 자리에 **빈 껍데기 폴더**가 남아 `list` 가 조용히 0건.
