# 재해영향평가(본) — 카테고리 공통 규칙

> 표본 1건 (2026-09-01): **횡성_조항리** 태양광 (재25-31, 2026.07 수정초안 — 표지 유형 검증 완료).
> ⚠️ n=1 — 아래는 전부 관측이지 규칙이 아니다. 변이표는 `golden/small-disaster/_variants.md` §4.

## 1. 골격 — **소재평과 동일, rule 준용** (실측 확정)

8장 구조·절 구성이 소재평(`rules/small-disaster/`)과 1:1 로 실측 일치했다
(전환계획 §2-2 ⑤ 예측 그대로). **소재평 파트 rule 을 준용**하고 아래 차이만 얹는다:

| 차이 | 실측 (횡성 1건) |
|---|---|
| 3장 절 승격 | **3.5 사면현황 조사**·**3.7 재해관련 지구지정 현황 조사**가 별도 절 |
| 6장 추가 절 | 6.5 벌칙 및 양벌규정과 과태료 |
| 1장 개요 불릿 | 사업유형에 `면적개념` · **사업 규모**(면적 대신) · **사 업 비** 추가 |
| 조서 명칭 | `[표 1-1] 토지편입조서` (소재평 `신청면적 조서`) — 표 번호가 캡션에 붙는다 |
| 5장 | 영구침사지 겸 저류지 (항구 저감시설 확대 — 계획 §2-2 ⑤) |

## 2. ⚠️ 수확 경로 — hwp 챕터가 없다 (PDF 전용)

NAS 재평은 **zip 안 PDF 뿐**이다 (hwp 는 표지만 — Windows 실측 09-01). `pypdfium2` 로
추출하며, 그 결과:

- **절 번호가 텍스트로 살아 있다** (`1.1`·`[표 1-1]`) — hwp 추출의 `楴䵴` 마커 파싱과
  **다른 파서**를 쓴다 (절번호 정규식. 소수점 오탐 `0.002 mm` 주의).
- 줄바꿈이 조판 기준이라 문장이 중간에 갈린다 — 문형 대조 때 이어 붙여 볼 것.
- ⚠️ **베이스로 쓸 수 없다** — PDF 는 빈칸을 뚫을 원본이 아니다. 재평 베이스는
  소재평 베이스에서 위 차이(절 승격·불릿 변형)를 반영해 만드는 경로가 현실적 (판단 대기).

## 3. 베이스 경로 — **소재평 파생으로 확정** (2026-09-03 Mac 판단)

§2 의 "판단 대기"를 닫는다. 재평 베이스는 **소재평 베이스(천안 서식 세트)를 그대로 쓴다** —
`templates/disaster-impact/*.spec.py` 8종이 소재평 spec 을 복사(import)하고, `engine/parts/disaster-impact/`
8종이 소재평 핸들러에 위임한다. 재평 고유 차이(§1 표)는 spec `재평_차이` 목록으로 **사람 보완 자리**에
둔다 — 절 삽입(3.5·3.7·6.5·영구침사지)은 엔진이 못 하는 부류(소환 할 일 2)라 러프 밖.

**골격 일치 실측** — 소재평 spec 의 고정 골격(토큰을 와일드카드로)이 횡성 재평 골든에 있는 비율:
1장 6/10 · 3장 2/8 · 4장 4/5 · 5장 9/12 = **21/35 (60%)**. 3장이 가장 멀다(표고·경사·기상개황 문장 꼴).
즉 재평 산출물은 소재평 틀의 60% 위에 `[확인 필요]` 와 차이 목록이 얹힌 **C 프레임**이다 — 커버리지
사다리 0.5(spec+핸들러 준용). 다른-사업 검증은 횡성_조항리 vars(1·2장, 골든 PDF 값)로.
채점 ✅ (09-03) — `score_part --category disaster-impact` 가 **절번호 파서**로 돈다: 골든(PDF)은 조판 줄바꿈을
이어붙인 뒤(`_join_wrapped`) 절번호 줄에서 **번호를 벗긴 제목 집합**으로 묶고, 산출물(소재평 파생 — 번호가
자동필드)은 제목 텍스트로 같은 키에 묶인다. 본환·전략도 같은 파서(번호가 평문이라 잇기 불필요).
첫 가동: 횡성 1장 14.3%(vars 1·2장뿐인 C 프레임 — 예상 범위). 아티팩트 2부류: 표 `set()` 빈 대조(기존 부류)·
줄 잇기 경계에서 문장 조각 2건.
