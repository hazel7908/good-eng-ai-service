# _archive — 보관소

여기 있는 것은 **현행 자산이 아니다.** 지난 단계의 산출물을 당시 모습 그대로 보관한다.

## 운용 규칙 (`docs/repo_restructure_plan.md` §8)

| 항목 | 규칙 |
|---|---|
| 내부 구조 | **당시 그대로.** 옮긴 뒤 손대지 않는다 |
| 경로 스코핑 | `_archive/**` 에는 **어떤 rule도 걸지 않는다.** 옛 지식이 컨텍스트에 새어 들어오면 안 된다 |
| 검색 | grep·탐색에서 **제외**한다. 현행 파일을 찾을 때 옛 사본이 섞이면 오히려 해롭다 |
| 종료 조건 | **6개월간 참조가 없으면 삭제** (2027-01 재검토) |

> 삭제해도 안전하다 — 태그 `poc-v1`(커밋 `d9c8bb8`)에 전부 들어 있어 언제든 복원할 수 있다.
> 이 폴더는 접근 편의를 위한 순수 안전망이다.
