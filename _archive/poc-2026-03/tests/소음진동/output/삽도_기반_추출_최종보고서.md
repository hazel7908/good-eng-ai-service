# 삽도(JPG) 기반 현장조사 데이터 추출 및 HWPX 보고서 완성 — 최종 결과 보고서

## 1. 실험 목적

소음·진동 PoC에서 AI가 생성한 보고서의 `[확인 필요]` 84건은 현장조사 데이터(영향예측지점, 이격거리 등)에 해당한다.
이 정보가 삽도(JPG 위성사진)에 포함되어 있으므로, 삽도를 인풋으로 활용하면 자동화 범위를 80% → 90%+ 로 확장 가능한지 검증한다.

**핵심 원칙**: 괴산 금신리 정답지를 보지 않고, 레퍼런스 4개에서 학습한 패턴만으로 괴산 삽도에서 데이터를 추출한다.

## 2. 삽도 분석 방법론

### 2.1 삽도 3종의 역할

모든 프로젝트가 공통으로 3종의 삽도를 보유:

| 삽도 종류 | 파일명 (괴산) | 포함 정보 | 미포함 정보 |
|----------|-------------|----------|-----------|
| 영향예측지점도 | `대기, 소음진동 영향예측지점.jpg` | P-1~P-N 라벨, 동심원(0.25/0.5/0.75/1.0km) | 시설명 |
| 정온/개발시설도 | `개발시설, 정온시설.jpg` | 시설명(민가, 축사, 마을 등), 위치, 유형(녹색=정온/주황=개발) | P번호 |
| 측정지점도 | `소음진동 측정지점.jpg` | N·V-1 위치, 동심원 | 이격거리 수치 |

### 2.2 교차 대조 매핑 기법

**P번호와 시설명이 항상 별도 이미지에 있으므로**, 두 이미지의 공간 위치를 교차 대조하여 매핑한다:

```
[영향예측지점도]          [정온시설도]
  P-1 (북서, 가까움)  ←→  민가1 (북서, 가까움)     → P-1 = 민가1
  P-2 (서, 중간)      ←→  축사2 (서, 중간)         → P-2 = 축사2
  P-3 (남, 가까움)    ←→  민가3 (남, 가까움)       → P-3 = 민가3
  ...
```

### 2.3 이격거리 추정 방법

동심원 기준으로 P 마커의 상대 위치를 읽어 거리를 추정:
- 동심원 내부(중심~0.25km) → 0~250m 범위에서 비례 추정
- 동심원 사이(0.25~0.5km) → 250~500m 범위에서 비례 추정
- 정밀도 한계: 동심원 간격 250m 단위이므로 ±50~100m 오차 불가피

### 2.4 방향 추정 방법

위성사진 내 프로젝트 중심 대비 P 마커의 상대 위치에서 8방위(북/북동/동/남동/남/남서/서/북서) 추론.

## 7. 오류 원인 분석

### 7.1 이격거리 오류 패턴

| 오류 유형 | 해당 지점 | 원인 |
|----------|----------|------|
| 근거리 과대추정 | P-3(175→250), P-4(151→350) | 0.25km 동심원 내부에서 세밀한 거리 구분 불가 |
| 원거리 과대추정 | P-8(690→850) | 0.75~1.0km 구간에서 비례 추정 오차 |
| 중거리 과소추정 | P-5(450→350) | 0.25~0.5km 구간 내 위치 판독 오차 |

**가장 큰 오류**: P-4 축사3은 실제 151m(매우 가까움)이지만 350m로 추정. 영향예측지점도에서 P-4가 동심원 바깥쪽에 있는 것처럼 보였으나, 실제로는 프로젝트 경계에서 불과 151m 거리.

### 7.2 시설명 매핑 오류 패턴

| 오류 지점 | 원인 |
|----------|------|
| P-5: 축사1 → 민가2 | 같은 북서 방향에 축사1(먼거리)과 민가2(중간)가 모두 존재. 가까운 쪽(민가2)을 선택했으나 실제 P-5는 더 먼 축사1 |
| P-7: 축사5 → 민가4 | 같은 동남 방향에 축사5와 민가4가 모두 존재. 위치 미세 차이 구별 실패 |

**공통점**: 같은 방향에 2개 이상 정온시설이 있을 때 어느 것이 P 포인트인지 구분 실패.

## 10. 결론 및 제언

### 결론

1. **삽도 기반 추출은 유효하다**: 방향(100%), 지점 수(100%), 시설명(75%)을 삽도만으로 추출 가능
2. **자동화 범위 80% → 88%로 확장**: `[확인 필요]` 84건 전부 해소
3. **이격거리가 핵심 병목**: 동심원(250m 간격) 기반 추정은 정밀도 50%로 한계
4. **계산 공식은 완벽**: 거리만 정확하면 소음/진동 예측 오차 ±0.4dB 이내

### 추천 운영 워크플로우

```
[현재 — 수작업]
실무자가 전체 보고서 수작업 작성 (4~5일)

[제안 — AI + 실무자 협업]
1. AI 삽도 분석 → 시설명·방향·거리 1차 추출 (자동, 수초)
2. AI 보고서 생성 → [확인 필요] 0건의 초안 (자동, 수초)
3. 실무자 이격거리 검증/수정 (수작업, 약 5~10분)
4. 수정된 거리로 자동 재계산 → 최종 보고서 (자동, 수초)
총 소요시간: 0.5~1일
```

### 향후 개선 방향

| 개선안 | 기대 효과 | 난이도 |
|--------|----------|--------|
| 이격거리 수치 삽도 활용 (청양 이격거리3.jpg 등) | 거리 정확도 50% → 90%+ | 낮음 |
| GIS 좌표 기반 거리 자동 계산 | 거리 100% 정확, 좌표도 해결 | 중간 |
| 고해상도 삽도 + OCR 강화 | 시설명 정확도 75% → 90%+ | 중간 |
| 실무자 보정 UI (웹) | 검증 시간 10분 → 3분 | 높음 |
