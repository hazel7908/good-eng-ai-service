**제공된 본문은 "소음·진동" 파트(섹션 7.2.7)이며, poc_plan.md에서 목표로 한 "대기질" 파트가 아닙니다.**

## 0-2. 레퍼런스 간 비교 분석

### (a) 문서 구조 매핑

#### 사업 개요 (제1장) — 5개 세트 공통 구조

```
1.1 사업의 배경 및 목적
1.2 소규모 환경영향평가 실시근거
    - 실시근거 표
    - 편입토지조서 표
    - 편입용지도 / 위성사진 / 위치도 (삽도)
1.3 추진경위 및 향후 계획
1.4 사업의 내용
    1.4.1 일반내용 (사업명, 범위, 사업시행자, 허가권자)
    1.4.2 세부사업계획
        가. 토지이용계획 표
        나. 태양광시설물(발전설비) 계획 표
        다. 피해방지계획 표
        - 피해방지계획도 (삽도)
```

**구조 일치도: 95% 이상** — 섹션 순서, 표 구조가 거의 동일

#### 소음·진동 (7.2.7) — 5개 세트 공통 구조

```
가. 현황
    (1) 소음·진동 발생원 현황
    (2) 소음·진동 현황(문헌자료)
        (가) 측정지점 표
        (나) 측정일시
        (다) 측정결과 (소음 표 + 진동 표)
    - 소음환경기준 표 (법령)
    - 생활소음 규제기준 표 (법령)
    - 생활진동 규제기준 표 (법령)
    - 환경분쟁 피해배상액 산정기준
나. 사업시행으로 인한 영향예측
    (1) 영향예측내용 표
    (2) 영향예측지점 표 + 지점도 (삽도)
    (3) 영향예측방법
        (가) 투입장비별 소음·진동도 표
        (나) 소음 (합성소음도 공식)
        (다) 진동 (거리감쇠 공식)
    (4) 영향예측결과
        (가) 투입장비 대수 산정 표
        (나) 소음 (목표기준 → 합성소음도 표 → 이격거리별 표 → 정온시설 예측 표)
        (다) 진동 (목표기준 → 합성진동레벨 표 → 이격거리별 표 → 정온시설 예측 표)
다. 저감방안
    (1) 환경보전목표 설정 표
    (2) 공사시
        (가) 일반적인 저감방안
        (나) 소음 저감 (저소음 장비 표)
        (다) 진동 저감
```

**구조 일치도: 90% 이상** — 매우 정형적

## 0-4. PoC 방향 판단

### 결론: **매우 유망 — GO 판단 가능성 높음**

1. **구조 정형성이 매우 높음** (90~95% 일치)
   - 섹션 순서, 표 구조, 법령 인용이 거의 동일
   - AI가 "템플릿 + 변수 치환" 방식으로 충분히 생성 가능

2. **고정+치환 영역이 80% 이상**
   - 법령 인용, 기준표, 공식 등은 레퍼런스에서 그대로 가져오면 됨
   - 지역명/수치만 치환하면 되는 부분이 대부분

3. **토큰 제약 없음**
   - 레퍼런스 3~5세트 + 인풋을 모두 컨텍스트에 넣을 수 있음
   - 일괄 생성(전략 B) 가능

4. **변수 출처가 명확**
   - 대부분 사업개요와 측정성적서에서 추출 가능
   - 외부 데이터 의존도 낮음
